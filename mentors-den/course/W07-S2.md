## 二、主循环的样子（4 分钟）

发动机是一个 `while` 循环（W05 老朋友）：

```python
print("=== Cat Adventure ===")
print("You are a young cat warrior. Find your way to the top!")

room = "shrine"

while room != "quit":
    if room == "shrine":
        print("\n--- Cat Shrine ---")
        print("You stand at the old shrine. Paths lead north and east.")
        choice = input("> ")
        if choice == "north":
            room = "forest"
        elif choice == "east":
            room == "riverbank"
```

逐行看懂：

- `room = "shrine"`：从神社出发，`room` 记住「我在哪」
- `while room != "quit"`：不是 `"quit"` 就一直转
- `if room == "shrine"`：站神社放神社剧情
- `choice = input("> ")`：问走哪边
- `room = "forest"`：换新值，下一圈进树林分支

**房间 = 一个 if 分支**：每圈先看 `room`，再放对应剧情。

## 三、补完另外两个房间（3 分钟）

在 `while` 里接着写 `elif`：

```python
while room != "quit":
    if room == "shrine":
        pass
    elif room == "forest":
        print("--- Whispering Forest ---")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
    elif room == "riverbank":
        print("--- River Bank ---")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
```

三个分支拼起来，shrine ↔ forest、shrine ↔ riverbank 通了。**每条连线都要双向走通。**

## 四、藏了一颗地雷：`==` 写成赋值（2 分钟）

看第二节神社代码最后两行：

```text
if choice == "north":
    room = "forest"          # 一个等号：装进去，走！
elif choice == "east":
    room == "riverbank"      # 两个等号：只是比较，啥也没发生！
```

W03-S3 的坑又来了：`==` 只是**比一比**，比完啥也不发生、不报错。症状诡异——输入 east「没反应」，永远困在神社。

**作业第一题就是排这颗雷**：改成单等号赋值，east 才生效。不报错的 bug 比报错的更狡猾——「没反应」时先查等号。

**今日口诀：** 房间是分支，换房靠赋值；没反应的 bug，先查等号数。
