## 二、主循环的样子（4 分钟）

整个游戏的发动机是一个 `while` 循环（W05 老朋友）：

```python
print("=== Cat Adventure ===")
print("You are a young cat warrior. Find your way to the top!")

room = "shrine"

while room != "quit":
    if room == "shrine":
        print("\n--- Cat Shrine ---")
        print("You stand at the old shrine. Paths lead north and east.")
        choice = input("> ")
        if choice == "north":
            room = "forest"
        elif choice == "east":
            room == "riverbank"
```

逐行看懂它：

- `room = "shrine"`：玩家从神社出发，`room` 记住「我现在在哪」
- `while room != "quit"`：只要 `room` 不是 `"quit"`，游戏一直转
- `if room == "shrine"`：站在神社，就执行神社的剧情
- `choice = input("> ")`：问玩家走哪边
- `room = "forest"`：把 `room` 换新值——下一圈循环就走进树林分支

**这就是「房间 = 一个 if 分支」**：主循环每一圈，先看 `room` 是谁，再放对应剧情。

## 三、补完另外两个房间（3 分钟）

在 `while` 里接着写 `elif`：

```python
    elif room == "forest":
        print("\n--- Whispering Forest ---")
        print("Tall trees rustle around you. You see a feather on the ground.")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
    elif room == "riverbank":
        print("\n--- River Bank ---")
        print("The river rushes past. A log bridge crosses to the north.")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
```

三个分支拼起来，shrine ↔ forest、shrine ↔ riverbank 就通了。输入 north 去 forest，再输入 south 回 shrine——**走一圈验证每条连线都是双向的**。

## 四、藏了一颗地雷：`==` 写成赋值（2 分钟）

仔细看第二节神社代码的最后两行：

```text
if choice == "north":
    room = "forest"          # 一个等号：装进去，走！
elif choice == "east":
    room == "riverbank"      # 两个等号：只是比较，啥也没发生！
```

W03-S3 踩过的坑又来了：`==` 是**比一比**，比较完什么都不发生，也不报错。症状很诡异——输入 east，程序「没反应」，永远困在神社。

**作业第一题就是排这颗雷**：把 `room == "riverbank"` 改成一个等号的 `room = "riverbank"`，east 才真正生效。不报错的 bug 比报错的更狡猾，症状是「没反应」时，先查等号。

**今日口诀：** 房间是分支，换房靠赋值；没反应的 bug，先查等号数。
