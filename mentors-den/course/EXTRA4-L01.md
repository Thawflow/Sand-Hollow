## 一、长老的分鱼干难题（5 分钟）

学徒在两脚兽的市场帮工，要找零 **68 分**钱。钱箱里四种硬币：

| 硬币 | 25 分 | 10 分 | 5 分 | 1 分 |
|---|---|---|---|---|
| 长相 | 大银 | 中银 | 小银 | 铜 |

**问题：怎么让硬币总数最少？**

先自己心算 30 秒，再往下看。（心算出来是几枚？）

你八成是这么算的：**抓两个 25（50 分）→ 剩 18，抓一个 10 → 剩 8，抓一个 5 → 剩 3，抓三个 1。总共 2+1+1+3 = 7 枚。**

恭喜——你刚用了**贪心算法（greedy algorithm）**：每一步都抓"当前能用的最大"，从不回头后悔。

## 二、贪心心法（5 分钟）

正式立碑：

> **贪心 = 每一步都选"眼下最好"的，赌局部最优堆出全局最优。**

- "眼下最好"：找零时 = 当前面值里**能塞进余额的最大**那枚
- "从不回头"：抓了 25 就不琢磨"要不要换 10 的组合"——决策一锤定音

贪心的脾气：**快**（不用把所有组合试一遍）、**简单**（三五行代码）；但有个致命弱点，第三节当场演示。

## 三、贪心翻车现场（10 分钟）

两脚兽市场换了个零钱系统，只有三种硬币：**4 分、3 分、1 分**。还是找 6 分。

**贪心的算法**：抓 4（剩 2）→ 4 塞不下了，抓不了 3（3 > 2），抓 1（剩 1）→ 再抓 1。总计 **4 + 1 + 1 = 3 枚**。

**更好的办法**：3 + 3 = 6，**只要 2 枚**！

贪心输了。它一步一步都"眼下最好"，合起来却**不是全局最好**——每一步的贪，可能把后面的路堵死（抓了 4，剩下的 2 就只能靠铜板凑）。

所以用贪心之前必须先问一句：**这道题的面值（规则）配不配得上贪心？** 25/10/5/1 这种"大面值能被小面值优雅覆盖"的系统配；4/3/1 就不配。**验货方法是找反例**——这是今天最重要的一招：贪心题，先试着拆台。

## 四、代码：贪心找零（10 分钟）

```python
def greedy_coins(amount, coins):
    """coins 从大到小排好；返回 (硬币列表, 总枚数)"""
    coins = sorted(coins, reverse=True)   # 先从大到小摆好（W11 之后再认这个sorted）
    picked = []
    for c in coins:
        while amount >= c:                # 这枚能塞就继续塞
            picked.append(c)
            amount = amount - c
    return picked, len(picked)

print(greedy_coins(68, [25, 10, 5, 1]))   # 先猜再跑
print(greedy_coins(6, [4, 3, 1]))         # 翻车现场，亲眼确认
```

**先猜两个输出再跑**。第一行应是 7 枚；第二行 `[4, 1, 1]` 3 枚——贪心在代码里翻车，和手算一致。

结构看两眼：

- `for c in coins`：从大到小逐个面值过堂（排序在最前面铺路——加餐③的排序在这儿当起了助手）
- `while amount >= c`：**"这枚还能塞就一直塞"**——贪心的"贪"字全在这个 while 里

## 六、练习答案（先做再看！）

**1.** `([25, 25, 10, 5, 1, 1, 1], 7)` 和 `([4, 1, 1], 3)`。

**2.** 25×3（剩 24）→ 10×2（剩 4）→ 5×0 → 1×4 → **9 枚**。

**3.** **16 翻车**：贪心 10+5+1 = 3 枚？等等——10+5+1 恰好也是 3 枚，没翻！真正的翻车金额如 **30**？10×3 = 3 枚也是最优……正确答案：**[10, 5, 1] 系统下贪心其实不翻车**（10 能被 5 整除、5 能被 1 整除，层层覆盖）——这道练习的真正考点是：**别轻信"肯定有反例"，验证了才算数**（就像本题的陷阱：出题人说"找一个"，但答案可以是"不存在"——先验证，再下结论）。真正会翻车的例子是第三节的 `[4, 3, 1]` 系统找 6。

**4.** `if` 只塞一枚就换下个面值：25×1、10×1、5×1、1×3 → 剩 25 没塞完？不对——注意 `if` 版每个面值只塞一次，68 - 25 - 10 - 5 - 1 = 27 分**找不开**，picked 只有 `[25, 10, 5, 1]` 4 枚且**余额没清零**。教训：`while` = 贪到塞不下，`if` = 客套一下就走。**贪心的"贪"不能打折。**

**5.** 提示（暴力版骨架）：

```python
def brute_best(amount, coins):
    best = amount            # 最笨方案：全用 1 分
    for c25 in range(amount // 25 + 1):
        for c10 in range(amount // 10 + 1):
            for c5 in range(amount // 5 + 1):
                left = amount - c25*25 - c10*10 - c5*5
                if left >= 0:
                    total = c25 + c10 + c5 + left
                    if total < best:
                        best = total
    return best
```

`[25,10,5,1]` 各种金额下 greedy 都 == brute_best；换 `[4,3,1]` 找 6，greedy 3 > brute 2，自首成功。

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天的找零，C++ 长这样：

```cpp
#include <iostream>
int main() {
    int coins[4] = {25, 10, 5, 1};        // 认脸①：数组摆面值，从大到小
    int money = 68, count = 0;
    for (int i = 0; i < 4; i++)           // 认脸②：逐面值过堂
        while (money >= coins[i]) {       // 认脸③：贪到塞不下（while 的贪）
            money = money - coins[i];
            count = count + 1;
        }
    std::cout << count;                   // 7
    return 0;
}
```

认脸要点：`coins[i]`（数组当脸谱用）、`while (money >= coins[i])`（贪心的心跳）。和 Python 逐行对号入座——**算法的心法不分语言**。
