## 一、概念：项目周的「先想后写」（5 分钟）

前 6 周都是一课一招式。今天开始做一个**完整的游戏**——文字冒险「猫咪冒险岛」。

游戏需要：

- 玩家能走、能看东西、能战斗
- 一个地图（5-7 个房间）
- 敌人 + 道具 + 胜负判定

**别急着写代码！** 今天只做一件事：**画地图、列房间、想清楚连接关系**。代码明天再写。

## 二、设计图（15 分钟）

打开草稿纸（真的，**先纸后码**）画一张这样的图：

画一个 ASCII 地图示例（**用中文**——这里不是代码块，是文字示意）：

- `[ 山洞入口 ]` 在最上面
- 下面是 `[ 橡树林 ]` 和 `[ 河边 ]`
- 中间是 `[ 营地 ]`，通过独木桥连 `[ 河边 ]`

- 最下面是 `[ Boss 巢穴 ]`

每个方块是「一个房间」，线是「可以走过去的路径」。**没有线的房间，玩家走不到**。

### 关键设计问题

边画边回答：

1. **几个房间？** 5-7 个最适合新手周。多于 10 个难维护，少于 4 个没探索感
2. **起点在哪？** 一个入口，玩家从这里开始
3. **终点在哪？** 一个 Boss 房间，玩家要走到这里赢
4. **有没有岔路？** 1-2 个岔路增加探索感，多了新手会迷路
5. **哪些房间有敌人 / 道具？** 标在地图上

## 三、最小骨架（10 分钟）

设计确认后，写一个**最小可跑**的代码——先能跑，再加东西：

新建 `cat_adventure.py`：

```python
print("=== Cat Adventure ===")
print("You are a young cat warrior. Find your way to the top!")

room = "shrine"

while room != "quit":
    if room == "shrine":
        print("\n--- Cat Shrine ---")
        print("You stand at the old shrine. Paths lead north and east.")
        choice = input("> ")
        if choice == "north":
            room = "forest"
        elif choice == "east":
            room == "riverbank"
        # Add more rooms as you build them
    elif room == "forest":
        print("\n--- Whispering Forest ---")
        print("Tall trees rustle around you. You see a feather on the ground.")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
    elif room == "riverbank":
        print("\n--- River Bank ---")
        print("The river rushes past. A log bridge crosses to the north.")
        choice = input("> ")
        if choice == "south":
            room = "shrine"
        elif choice == "north":
            room = "bridge"
```

### 注意

- **故意错**：上面 `room = "riverbank"` 被故意写成了 `room == "riverbank"`（多打一个等号）——`==` 是比较、`=` 是赋值；比较完什么都不发生，**也不报错**，症状是：输入 east 程序「没反应」，永远困在 shrine。**找到这行、改成一个等号的 `room = "riverbank"` 再跑**
- **测试**：跑通后试 north / east / south，看能不能走通 shrine ↔ forest / shrine ↔ riverbank
