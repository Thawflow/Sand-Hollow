## 一、动态数组核心（3 分钟）

Python list 内部 = **C 数组**（连续内存） + **容量管理**。

```
Operation     | Complexity | Why
--------------|--------|----------------------
list[i]       | O(1)   | direct jump
list.append(x)| O(1)*  | capacity enough
list.insert(0)| O(n)   | all shift right
list.pop()    | O(1)   | tail pop
list.remove(x)| O(n)   | find + shift
x in list     | O(n)   | scan one by one
```

*Amortized O(1) = average O(1), occasionally O(n) (capacity double).

## 二、容量翻倍策略（5 分钟）

**为什么 `append` 是 O(1) 摊销**？

```python
# simplified list implementation
class SimpleList:
    def __init__(self):
        self.capacity = 1
        self.size = 0
        self.data = [None] * self.capacity

    def append(self, x):
        if self.size == self.capacity:
            self._resize()
        self.data[self.size] = x
        self.size += 1

    def _resize(self):
        '''Double capacity when full.'''
        new_capacity = self.capacity * 2
        new_data = [None] * new_capacity
        for i in range(self.size):
            new_data[i] = self.data[i]
        self.data = new_data
        self.capacity = new_capacity
```

**为什么 O(1) 摊销**：resize 罕见（按对数频次），平均下来每步 O(1)。

## 三、示例演算：append 8 次（3 分钟）

| 步 | size | capacity | 操作 |
|---|---|---|---|
| 1 | 1 | 1 | append → fill |
| 2 | 2 | 2 | append → resize 1→2 |
| 3 | 3 | 4 | append → resize 2→4 |
| 4 | 4 | 4 | append |
| 5 | 5 | 8 | append → resize 4→8 |
| ... | ... | ... | ... |

**resize 总次数**：log₂(8) = 3 次。8 个 append 8 步 + 3 步 resize = 11 步。平均 11/8 ≈ 1.4 步 = **O(1) 摊销**。

## 四、深入了解：为什么不用链表（3 分钟）

链表在 Python 里**几乎没用**：
- 链表多 2x 内存（每个节点要 2 个指针）
- 链表 cache 不友好（节点不连续）
- Python list 已经够用

**什么时候用链表**：
- 需要频繁中间插入（数据库 B 树）
- 大数据（> 10⁹）放不进内存

**AI 工程师原则**：**99% 用 list**。

## 七、答案

```python
import time, sys

# 1
benchmark()  # append fast, insert(0) slow

# 2
class SimpleList:
    def __init__(self):
        self.capacity = 1
        self.size = 0
        self.data = [None]
    def append(self, x):
        if self.size == self.capacity:
            self.capacity *= 2
            self.data = self.data + [None]
        self.data[self.size] = x
        self.size += 1
    def insert(self, i, x):
        # Shift right
        self.append(None)  # make room
        for j in range(self.size - 1, i, -1):
            self.data[j] = self.data[j-1]
        self.data[i] = x

# 3
sizes = [0, 1, 10, 100, 1000, 10000]
for s in sizes:
    lst = list(range(s))
    print(f'len={s}: size={sys.getsizeof(lst)} bytes')
```

## 👀 C++ 认脸时刻

```cpp
#include <vector>
int main() {
    std::vector<int> v;
    v.push_back(1);              // O(1) amortized
    v.insert(v.begin(), 0);     // O(n)
    return 0;
}
```

三个认脸：
- `std::vector` = Python list（动态数组）
- `v.push_back(1)` = Python `v.append(1)`
- `v.insert(begin, 0)` = Python `v.insert(0, 0)`
