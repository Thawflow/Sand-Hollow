## 一、今天的目标（3 分钟）

## 二、先写"逐格搜"当对照组（8 分钟）

部族猎物名册（已按字母排好序）里找 `"sparrow"`。笨办法先来：

```python
prey = ["fish", "mouse", "rabbit", "sparrow", "squirrel", "vole"]

def slow_search(name, roster):
    """逐格搜：从头到尾一个个问"""
    steps = 0
    for item in roster:
        steps = steps + 1
        if item == name:
            return steps        # 找到了，返回用了几步
    return -1                   # -1 表示名册里没有

print(slow_search("sparrow", prey))    # 4 步
print(slow_search("vole", prey))       # 6 步（最坏要走到最后）
```

名册只有 6 项，逐格搜无所谓。但要是名册有 100 万项呢？——该二分出场了。

## 三、二分查找本体（15 分钟）

三个变量记住站位：**low（最左）、high（最右）、mid（正中间）**。

```python
prey = ["fish", "mouse", "rabbit", "sparrow", "squirrel", "vole"]

def binary_search(name, roster):
    """每次砍一半：返回用了几步，找不到返回 -1"""
    low = 0                      # 最左边的位置（列表从 0 开始数！）
    high = len(roster) - 1       # 最右边的位置
    steps = 0
    while low <= high:           # 只要还有格子剩，就继续砍
        steps = steps + 1
        mid = (low + high) // 2  # 正中间（// 是整除，只要商不要余数）
        if roster[mid] == name:
            return steps         # 🎯 命中
        elif roster[mid] < name:
            low = mid + 1        # 中间这个比目标小 → 目标在右半边
        else:
            high = mid - 1       # 中间这个比目标大 → 目标在左半边
    return -1                    # 砍完了还没有 → 名册里没有

print(binary_search("sparrow", prey))   # 3 步
print(binary_search("vole", prey))      # 3 步
print(binary_search("hawk", prey))      # -1（名册里没有）
```

**亲手敲完运行，盯住这三个对照**：

- `sparrow`：逐格 4 步 → 二分 3 步
- `vole`：逐格 6 步 → 二分 3 步（**越靠后，二分赢得越多**）
- `hawk`：逐格 6 步才知道没有 → 二分 3 步就知道没有

### 逐行拆解三个关键

| 代码 | 一句话记忆 |
|---|---|
| `mid = (low + high) // 2` | 中间位置 =（左+右）整除 2。`7 // 2` 是 3 不是 3.5 |
| `low = mid + 1` | mid 自己已经问过了，右半边从 mid **+1** 开始 |
| `while low <= high` | 左超过右 = 雪原砍光了，还剩"负数格"就该停 |

### ⚠️ 三大坑（每个都值得故意踩）

1. **用 `/` 不用 `//`**：`mid = (low+high) / 2` 得到 3.5 → 列表位置必须是整数 → `TypeError`。改成 `//` 好了
2. **忘写 `+1` / `-1`**：`low = mid`（不加 1）→ 有时会永远卡在两个格子里转圈 → **死循环**。Ctrl+C 停下来，加回 `+1`
3. **列表没排序就二分**：把 `prey` 故意打乱试试——结果会错得莫名其妙。**无序，先排序**（昨天第四节说过）

## 四、给 W05 的猜数字装仪表盘（8 分钟）

把二分塞进 W05 那个游戏，让电脑自己证明"7 次必中"：

```python
import random

def guess_like_a_pro():
    secret = random.randint(1, 100)   # 电脑想一个 1-100 的数
    low, high, steps = 1, 100, 0
    while low <= high:
        steps = steps + 1
        mid = (low + high) // 2       # 电脑猜中间
        if mid == secret:
            break
        elif mid < secret:
            low = mid + 1
        else:
            high = mid - 1
    print(f"秘密是 {secret}，电脑用二分 {steps} 次猜中")

for i in range(5):                    # 玩 5 局看看
    guess_like_a_pro()
```

跑 5 局。有一局超过 7 次吗？**不可能有**——昨天算过 2⁷=128>100，这是数学担保的。

## 六、练习答案（先做再看！）

**1.** 三组对照结果见第三节注释（4→3、6→3、6→3）。

**2.** 16 项找最后一项：16→8→4→2→1，**4 步**（也可能 5 步，取决于中间落点——都在 ⌈log₂16⌉+1 以内）。2⁴=16，对上了。

**3.** 死循环发生在 `low == high - 1`（只剩两格）且 mid==low 时：`low = mid` 让 low 原地不动，永远在这两格打转。这就是为什么要 `mid + 1`——**把问过的格子彻底踢出去**。

**4.** `TypeError: list indices must be integers or slices, not float`。位置（索引）必须是整数。

**5.** 参考：

```python
def binary_search(name, roster, verbose=False):
    low, high, steps = 0, len(roster) - 1, 0
    while low <= high:
        steps = steps + 1
        mid = (low + high) // 2
        if verbose:
            print(f"第{steps}步: 问位置{mid}，剩下 {low}-{high}")
        if roster[mid] == name:
            return steps
        elif roster[mid] < name:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

默认 `verbose=False` 不吵，需要追踪表时才开——**给函数加开关**是 W08 学过的默认参数。

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天的 `binary_search`，C++ 版几乎逐行能对上号：

```cpp
int binary_search(int a[], int n, int x) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (a[mid] == x) return mid;
        else if (a[mid] < x) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
```

- **认脸①**：每个变量前面都有个 `int`——C++ 变量要先"报名字 + 报类型"（Python 不用）
- **认脸②**：`else if` 就是 Python 的 `elif`，C++ 要写全
- **认脸③**：`(low + high) / 2` 用普通除号 `/`——两个整数相除，C++ **自动只留整数**（今天踩的 `//` 坑，在 C++ 里天生不存在）
