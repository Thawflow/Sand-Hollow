## 一、概念：写一次，处处调用（5 分钟）

W07 项目周你已经用过 `def battle(...)` 和 `def use_item(...)`。**函数 = 一段有名字的代码**，可以反复调用。

```python
# Without def: copy-paste fight code everywhere
# With def: write once, call N times
def attack(player, enemy, dmg):
    enemy["hp"] -= dmg
    print(f"You hit {enemy['name']} for {dmg}")
```

**为什么要用函数？**

- **避免重复**：同一段代码不写 10 遍
- **便于修改**：改一处，处处生效
- **代码可读**：`battle(player, wolf)` 比 30 行战斗代码易读

## 二、def 的样子（8 分钟）

新建 `first_def.py`，亲手敲：

```python
def greet(name):
    print(f"Hello, {name}!")
    print("Welcome to Python.")

greet("Alice")
greet("Bob")
greet("Charlie")
```

运行得：

```
Hello, Alice!
Welcome to Python.
Hello, Bob!
Welcome to Python.
Hello, Charlie!
Welcome to Python.
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `def` | 定义（define）的缩写 |
| `greet` | 函数名（自己起，最好是动词） |
| `(name)` | **参数**：调用时传进来的数据 |
| `:` | 冒号，下面缩进的函数体 |
| 缩进 | 函数体（属于这个函数的代码） |

**关键观察：** 函数体不缩进的代码不属于函数。`greet("Alice")` 顶格写，是「调用函数」。

## 三、不带参数的函数（5 分钟）

```python
def print_menu():
    print("1. New Game")
    print("2. Load Game")
    print("3. Quit")

print_menu()
print("---")
print_menu()
```

`print_menu()` 没有参数，每次调用都打印相同菜单。**适用场景**：固定输出、初始化、帮助文本。

## 四、调用 = 执行函数体（5 分钟）

`def` 只是**定义**，不执行。**调用**才会执行：

```python
def say_hello():
    print("Hello!")

# This does nothing yet
say_hello  # Just the function object, no call

# This actually calls it
say_hello()  # With parentheses = execute
```

**`name` vs `name()`：**
- `say_hello` 是函数对象（可以传递、可以赋值给别的变量）
- `say_hello()` 是调用（执行函数体）

## 五、实战：抽函数（10 分钟）

W06-L01 的班干部名单，可以抽成函数：

```python
def print_class(names):
    print(f"Class size: {len(names)}")
    for name in names:
        print(f"- {name}")

my_class = ["Alice", "Bob", "Charlie"]
print_class(my_class)

friends = ["Diana", "Eve"]
print_class(friends)
```

跑两遍看到：**同一份代码，两份数据，两份输出**。这就是函数的威力。

## 六、⚠️ 新手三大坑（5 分钟）

1. **忘写括号**：`greet` 不报错但什么都不做。**调用必须加 ()**
2. **缩进错**：函数体没缩进 4 格 → IndentationError 或「print 永远只打一次」
3. **def 后没冒号**：`def greet(name)` 漏 `:` → SyntaxError

老规矩：三个坑各故意踩一次，读报错，再修好。
