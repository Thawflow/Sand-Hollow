## 一、核心想法（3 分钟）

**数组 = 火车站**：座位连号（1, 2, ..., 100），找第 50 号 → 立刻知道。
- 找第 N 个：O(1)
- 中间插入：O(n)

**链表 = 接力赛**：每人只记得下一个。找第 50 号 → 从 1 数到 50。
- 找第 N 个：O(n)
- 中间插入：O(1)

## 二、Python list 实际是数组（3 分钟）

```python
my_list = [10, 20, 30, 40, 50]
print(my_list[2])   # 30  (O(1) instant access)
```

**Python 标准库没"纯链表"**——list 是数组。要链表用 `collections.deque`。

## 三、Python list 的插入代价（3 分钟）

```python
my_list = [10, 20, 30, 40, 50]
my_list.insert(2, 25)
# my_list is now [10, 20, 25, 30, 40, 50]
```

**内部做了什么**：
1. 25 占位到位置 2
2. 30, 40, 50 全部后挪一格（O(3)）

N 个元素 + 中间插入 = O(n) 后挪。

## 四、手写简单链表（5 分钟）

```python
class Node:
    '''A linked list node: holds data and points to next.'''
    def __init__(self, data):
        self.data = data
        self.next = None

# Build: 1 -> 2 -> 3 -> None
node1 = Node(1)
node2 = Node(2)
node3 = Node(3)
node1.next = node2
node2.next = node3

# Walk: print all
current = node1
while current is not None:
    print(current.data, end=' ')
    current = current.next
# 1 2 3
```

## 五、深入了解：选对数据结构 = 性能翻倍（3 分钟）

**AI 工程师面试必问**："这个场景用什么数据结构？"——选错 = 慢 10 倍。

| 场景 | 选 | 原因 |
|---|---|---|
| 随机访问（下标）| 数组 | O(1) |
| 中间插入删除 | 链表 | O(1) |
| 数据小（< 100）| 都行 | 差距忽略 |
| 内存紧张 | 数组 | 链表每个节点要 2 个指针 |

**Python 默认 list = 数组**——别自己造链表。

## 👀 C++ 认脸时刻

```cpp
#include <vector>
#include <list>
int main() {
    std::vector<int> arr = {1, 2, 3, 4, 5};        // dynamic array
    std::list<int> lst = {1, 2, 3, 4, 5};         // doubly linked list
    arr[2] = 99;       // O(1): array random access
    lst.push_back(6);  // O(1): list tail insert
    return 0;
}
```

三个认脸：
- `std::vector` = 动态数组（Python list）
- `std::list` = 双向链表
- `arr[2] = 99` = Python 下标访问
