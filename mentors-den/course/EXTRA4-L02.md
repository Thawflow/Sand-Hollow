## 二、巡逻排班：结束早的先上（15 分钟）

### 题目

四只猫报名巡逻，时段会重叠。**族规：一只猫不能连轴转，巡逻不能重叠**（一只巡逻时，下一只必须等它结束）。最多能排几班？

| 猫 | 开始 | 结束 |
|---|---|---|
| 灰纹 | 1 | 4 |
| 冬毛 | 2 | 3 |
| 黑莓 | 3 | 6 |
| 黄牙 | 5 | 7 |

### 先手玩（3 分钟，拿纸笔画时间轴）

画一条 1-7 的数轴，每只猫的时段画一条横线。**试试最多能同时排下几段不重叠的？**（先猜再往下看。）

### 贪心的正确姿势：按"结束时间"排

上节课按面值从大到小，这次不一样——**把班按结束时间从早到晚排，每轮选"结束最早且不与已选重叠"的**：

1. 按结束时间重排：冬毛(2-3)、灰纹(1-4)、黑莓(3-6)、黄牙(5-7)
2. 选冬毛（最早结束，2-3）
3. 灰纹 1-4：开始 1 < 3，**和冬毛重叠**，跳过
4. 黑莓 3-6：开始 3 ≥ 3（冬毛结束），**不重叠**，选！
5. 黄牙 5-7：开始 5 < 6，和黑莓重叠，跳过

最终：**冬毛 + 黑莓 = 2 班**。你手玩对了吗？

为什么"结束早的先上"是对的？直觉：**结束越早，给后面留的地盘越大**——每一步都最大化"余下的可能性"，这正是贪心在这道题上不翻车的原因（证明寒假正篇补，现在记住直觉就够）。

⚠️ 注意排序的钥匙是**结束时间**，不是开始时间、也不是时长最短——排错钥匙，贪心照样翻车（练习 3 让你亲手翻一次）。

### 代码

```python
def patrol_count(shifts):
    """shifts: [(开始, 结束), ...] 返回最多不重叠班数"""
    shifts = sorted(shifts, key=lambda s: s[1])   # 按结束时间排（钥匙！）
    count = 0
    last_end = 0
    for start, end in shifts:
        if start >= last_end:      # 和上一班不重叠
            count = count + 1
            last_end = end         # 更新"下一班必须晚于"的时刻
    return count

plan = [(1, 4), (2, 3), (3, 6), (5, 7)]
print(patrol_count(plan))          # 先猜再跑：2
```

## 三、采药背包：贪心的务实（10 分钟）

### 题目

巫医去采药，背包容积 **10**。药草四种（各一株，不可拆分）：

| 药草 | 体积 |
|---|---|
| 止咳叶 | 4 |
| 退烧花 | 5 |
| 镇痛草 | 3 |
| 安神苔 | 2 |

背包装到"装不下"为止，求装进最多体积。

### 贪心版：小的先装

排序 2、3、4、5 → 装 2（剩 8）→ 装 3（剩 5）→ 装 4（剩 1）→ 5 塞不进，停。**装进 2+3+4 = 9**。

```python
def greedy_pack(items, bag):
    """items: 体积列表；小的先装；返回装进总体积"""
    items = sorted(items)
    total = 0
    for w in items:
        if w <= bag - total:       # 还装得下才装
            total = total + w
    return total

print(greedy_pack([4, 5, 3, 2], 10))    # 先猜再跑
```

### 贪心是最优吗？——不一定！

换一组：背包容积 10，药草 `[6, 5, 5]`。贪心（小先）：5 + 5 = **10**，恰好最优。再换 `[9, 8, 6, 5]` 容积 10：贪心装 5（剩 5，后面 6、8、9 全塞不下）= **5**；但最优是 **9**（单装 9）！贪心被"小块陷阱"坑了。

这就是《算法图解》第 7 章的名场面：**贪心背包 = 快速给出"还不错"的近似解**（寒假要交卷、药箱要出发时，次优但秒出的方案很值钱）；**最优解要等"动态规划"**——正篇的大菜，先记住名字。

> 贪心使用说明书（三门课总结）：① 先找反例（找零 4/3/1）② 排对钥匙（排班按结束时间）③ 接受次优也是解（背包近似）。

## 五、练习答案（先做再看！）

**1.** 2 和 9。

**2.** 最多 **3 班**：冬毛(2-3)、火心(4-5)、黄牙(5-7)。注意火心的加入挤掉了别人——贪心按结束时间重排后：冬毛(2-3)、灰纹(1-4)、火心(4-5)、黑莓(3-6)、黄牙(5-7)，依次选冬毛（last_end=3）→ 灰纹 1<3 跳过 → 火心 4≥3 选（last_end=5）→ 黑莓 3<5 跳过 → 黄牙 5≥5 选。3 班。

**3.** 变成 **2 班**（灰纹、黄牙）。按开始时间排：灰纹(1-4) 先入选（last_end=4）→ 冬毛 2<4 跳过 → 黑莓 3<4 跳过 → 黄牙 5≥4 选。**冬毛被坑了**——它本是最该上的班（结束最早、最不挡路）。钥匙排错，好班被埋。

**4.** 贪心（小先）：4+5 = 9（剩 3，6、7 塞不下）；最优：**12 = 5+7 或 4+... 5+7=12 恰好满包**。贪心 9 vs 最优 12——又是"小块陷阱"。

**5.** 提示：

```python
def patrol_pick(shifts):
    shifts = sorted(shifts, key=lambda s: s[1])
    picked = []
    last_end = 0
    for start, end in shifts:
        if start >= last_end:
            picked.append((start, end))
            last_end = end
    return picked

print(patrol_pick([(1, 4), (2, 3), (3, 6), (5, 7)]))
# [(2, 3), (3, 6)]
```

## 六、🤖 AI 常识胶囊 · 第 12 颗：AI 能替代老师吗（4 分钟）

> AI 营面试真题（1 分钟限时）："AI 能替代老师吗？"——今天教你**面试答题三件套：观点一句 + 理由两句 + 例子一句**。

参考答案（背结构，别背字）：

> **观点**：AI 是超级助教，替代不了老师。**理由**：① AI 没有真人的期待和关系——老师会因为你昨天没交作业今天多问你一句，AI 不会主动在乎；② AI 有幻觉，需要懂行的人把关。**例子**：就像今天的贪心——AI 一秒给你"还不错"的方案，但判断"这是不是最优、要不要较真"，目前还得靠人。

留意这道题和"开源 vs 闭源"（胶囊④）一样是**观点题**：考的不是对错，是**你有没有自己的判断 + 说得清**。

**⚔️ 判一判（先自己答，再看答案）**

1. AI 能回答的问题比任何老师都多，所以老师会被 AI 淘汰。
2. 会用 AI 的学习者，比不会用的更有优势。

**答案**：1 ✗（"答得多"≠"教得好"——激励、关系、把关、因材施教都是人的活）；2 ✓（工具时代，用工具的人赢——这也是咱们一直攒胶囊的原因）。

## 七、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天的背包，C++ 长这样：

```cpp
#include <iostream>
int main() {
    int w[4] = {4, 5, 3, 2}, bag = 10, total = 0;
    for (int i = 0; i < 3; i++)              // 认脸①：选择排序（加餐③老朋友）小的在前
        for (int j = i + 1; j < 4; j++)
            if (w[j] < w[i]) { int t = w[i]; w[i] = w[j]; w[j] = t; }
    for (int i = 0; i < 4; i++)              // 认脸②：小的先装
        if (w[i] <= bag - total)
            total = total + w[i];
    std::cout << total;                      // 9
    return 0;
}
```

认脸要点：这段是**两课连招**——先排序（双循环）再贪心（单循环）。笔试见到"排完序再扫一遍"，八成就是贪心家族。
