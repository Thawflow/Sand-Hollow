    "claw": {"name": "Sharp Claw", "effect": "attack", "value": 3},

道具定义在字典里：每个道具名字、效果、数值。

### 加一个 use_item 函数

```python
def use_item(player, item_name):
    if item_name not in player["inventory"]:
        print(f"You don't have {item_name}")
        return False

    item = items_db[item_name]
    if item["effect"] == "heal":
        old = player["hp"]
        player["hp"] = min(player["max_hp"], player["hp"] + item["value"])
        print(f"Used {item['name']}! HP {old} -> {player['hp']}")
    elif item["effect"] == "attack":
        player["attack"] += item["value"]
        print(f"Used {item['name']}! ATK +{item['value']} (now {player['attack']})")

    player["inventory"].remove(item_name)
    return True
```

### 拆解

- **`if item_name not in player["inventory"]`**：先检查有没有，没有就退出
- **`item = items_db[item_name]`**：查道具定义
- **效果分发**：if heal 走回血，if attack 走加攻击
- **`min(player["max_hp"], ...)`**：回血不超过最大血量（W06-L02 的 max）
- **`player["inventory"].remove(item_name)`**：用完从道具栏删掉

### 在房间里加「捡道具」选项（贴到主循环 while 里）

## 五、常见翻车点（5 分钟）

- **房间之间跳错方向**：south 回 shrine，但 shrine 的 if 写的是 north 去 forest，跑几次确认方向对
- **道具栏多 / 少一个**：take herb 后 inventory 里应该有 herb，再 use 才能用。先 print(player["inventory"]) 看
- **Boss 太硬**：如果打 Boss 一直输，可以在 player["attack"] 临时调高（10 → 20）测试流程通

## 六、⚠️ 新手三大坑（5 分钟）
