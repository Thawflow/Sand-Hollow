# W05-L02 · break：喊停的艺术

> 用时：30-35 分钟 · 难度：⭐⭐ · 前置：W05-L01 (while)

## 一、概念：循环跑一半想跑？（5 分钟）

while 循环老老实实看条件。但有时候：**条件还没失败，我就要跑**。

- 密码对了 → 不用再问下去，立刻停
- 找到目标了 → 不用再翻下去，立刻停
- 出错了 → 不用再继续，立刻停

**break** 就是「喊停」——立刻跳出循环，不管条件。

## 二、break 的样子（8 分钟）

新建 `break_demo.py`，亲手敲：

```python
for i in range(1, 11):
    if i == 6:
        print("Found 6, stop!")
        break
    print(i)
```

运行得：

```
1
2
3
4
5
Found 6, stop!
```

`6` 没打印——循环到 6 时立刻 break 跳出了。

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `for i in range(1, 11)` | 计划数 1-10 |
| `if i == 6:` | 当 i 等于 6 |
| `break` | **喊停**：立刻跳出整个 for，后面的 7/8/9/10 全跳过 |

`break` 是循环里的「紧急出口」。

## 三、continue：跳过这一轮（5 分钟）

跟 break 相反：**continue 是「跳过这一轮，下一轮继续」**。

```python
for i in range(1, 11):
    if i == 6:
        continue
    print(i)
```

运行得：

```
1
2
3
4
5
7
8
9
10
```

`6` 没打印，但 7/8/9/10 继续打。**continue = 跳过当前，往下走**。

记忆口诀：**break 是跑，continue 是这一轮不玩**。

## 四、实战：密码 + 限 3 次（10 分钟）

实战场景：登录重试 3 次，封号。

```python
password = "thawpaw"
tries = 0
while tries < 3:
    guess = input("Password: ")
    if guess == password:
        print("Welcome!")
        break
    tries += 1
    print(f"Wrong! {3 - tries} tries left")
else:
    print("Account locked")
```

### 拆解

- `tries = 0`：起手 0 次
- `while tries < 3:`：最多 3 次机会
- `if guess == password:`：对了
  - `print("Welcome!")`
  - `break`：跳出循环，**不再问**
- `tries += 1`：用掉一次机会
- **`else:`** 是 while 的「正常走完」分支——3 次都没 break 才执行 → 锁账号

**Python 独家：** `while ... else:` 是「循环没被 break 才执行的 else」，初见有点怪，混个脸熟就好。

### Shell 追踪

输入 `wrong1` → tries=1 → 还剩 2 次 → 输入 `wrong2` → tries=2 → 还剩 1 次 → 输入 `thawpaw` → break → Welcome!

输入 `a` `b` `c` 三次错 → else 执行 → Account locked

## 五、用 break 找东西（7 分钟）

```python
nums = [12, 45, 7, 23, 56, 89, 34]
target = 23
found = False
for n in nums:
    if n == target:
        found = True
        break
if found:
    print(f"Found {target}!")
else:
    print(f"{target} not in list")
```

找到立刻停，找不到就走完整个循环。**效率比 for 走完再判断高**——列表大时省很多时间。

## 六、⚠️ 新手三大坑（5 分钟）

1. **break 写在 if 外面**：忘了缩进，`break` 不属于 if → 循环第一次就 break，连一次都没跑
2. **break 只能跳一层**：嵌套循环里 break 只跳内层，外层继续走（复杂场景，W07 项目周会用）
3. **while...else 误解**：以为 else 是 if 的 else（不是！它是 while 没被 break 才执行的）

老规矩：三个坑各故意踩一次，**break 写错缩进时** 现象是「循环一次都不跑」，不要慌，加缩进即可。
