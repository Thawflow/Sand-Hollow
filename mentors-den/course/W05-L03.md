## 二、第一版：基础猜数字（12 分钟）

新建文件，亲手敲：

```python
import random

print("=== Number Guess (Full Version) ===")

secret = random.randint(1, 100)
guess = 0

while guess != secret:
    guess = int(input("Your guess (1-100): "))
    if guess > secret:
        print("Too high!")
    elif guess < secret:
        print("Too low!")
    else:
        print(f"Correct! The answer was {secret}")
```

跑几局体会：**猜错会继续问，猜中就停**。

### 关键结构

骨架（**伪代码**，不是合法 Python）：

- `while guess != secret:`：条件 = 没猜对就继续
- 内层：input 读玩家猜的数
- 三分支判断：大了 / 小了 / 猜对

**W03 写一次就完，W05 写一次就一直问**——while 是灵魂。

## 三、第二版：限次数（10 分钟）

基础版没有次数限制，玩家可以猜 100 次。**改成限 5 次**：

```python
import random

print("=== Number Guess · Limited 5 ===")

secret = random.randint(1, 100)
guess = 0
tries = 0
max_tries = 5

while guess != secret and tries < max_tries:
    guess = int(input(f"Tries {tries+1}/{max_tries} - guess (1-100): "))
    tries += 1
    if guess > secret:
        print("Too high!")
    elif guess < secret:
        print("Too low!")
    else:
        print(f"Correct! You got it in {tries} tries")
        break
else:
    if guess != secret:
        print(f"Game over! The answer was {secret}")
```

### 关键改动

- `tries = 0`：起手 0 次
- `tries < max_tries`：第二个条件，最多 5 次
- `tries += 1`：每轮用掉一次（放在判断前，先 +1 再显示）
- `else:`：5 次都没猜中 → 揭底

**`while...else` 复习：** 循环没被 break 才执行 else。这里要么「猜中 break」要么「5 次用完正常走完」。

## 四、第三版：游戏循环（10 分钟）

玩完一局，再玩一局：

```python
import random

print("=== Number Guess · Multi-Round ===")

play_again = "yes"
while play_again == "yes":
    secret = random.randint(1, 100)
    guess = 0
    tries = 0

    while guess != secret and tries < 5:
        guess = int(input("Guess (1-100): "))
        tries += 1
        if guess > secret:
            print("Too high!")
        elif guess < secret:
            print("Too low!")
        else:
            print(f"Correct in {tries} tries!")
            break
    else:
        if guess != secret:
            print(f"Out of tries. Answer: {secret}")

    play_again = input("Play again? (yes/no): ")

print("Thanks for playing!")
```

### 拆解

- **外层 while**：玩 yes/no，外层控制多局
- **内层 while**：每局猜 5 次
- **嵌套循环**：W04-L03 学的技能，今天实战用上
- **每局重置**：secret / guess / tries 在外层内重新初始化

跑两局：第一局猜对退出内层 → 问 yes/no → yes 进第二局 → no 退出外层。

## 六、⚠️ 新手三大坑（5 分钟）

1. **忘 import random**：脚本开头没 `import random` → `NameError: name 'random' is not defined`（W03-weekend 提过）
2. **else 缩进错**：else 跟 while 同级（不缩进），不是跟 if 同级。错了现象：「猜对也走 else」
3. **tries 没用对位置**：`tries += 1` 放在判断后，导致「猜对也 +1」——但因为 break 跳出，不影响；猜错时多算一次，常见翻车

老规矩：三个坑各故意踩一次，读报错，再修好。
