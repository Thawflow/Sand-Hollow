## 一、今天的目标（3 分钟）

营地需要一份**按个头从小到大**排好的猎物名册。乱册在手：

```python
prey = ["vole", "sparrow", "mouse", "squirrel", "rabbit", "fish"]
```

怎么排？今天学最直白的一招——**选择排序（selection sort）**。它慢，但它是你读懂一切排序的第一级台阶；寒假正篇还有快它百倍的"快速排序"等着，台阶得一级级上。

## 二、心法：冠军席位 + 打擂台（10 分钟）

想象名册左边有一排**席位**，第 0 席是"全场最小"的专属座位。

- **第 1 轮**：全场打擂台，找出最小的（fish）→ 请上第 0 席（和原来坐 0 席的 vole **交换**）
- **第 2 轮**：剩下的人里再找最小 → 请上第 1 席
- ……每轮敲定一个席位，敲完全场，名册有序

关键两件事：

1. **"找最小"你早会了**——W06 写过的"打擂台找最大"，今天只是擂台摆进循环里一轮轮摆
2. **交换要用"空杯舞"**——两杯水互换，必须借第三个空杯：

```python
temp = a[i]        # 左杯的水先倒进空杯
a[i] = a[j]        # 右杯倒进左杯
a[j] = temp        # 空杯的水倒进右杯
```

## 三、代码：带计步器的选择排序（15 分钟）

```python
def selection_sort(roster):
    """打擂台排序，顺便数比较次数"""
    n = len(roster)
    compares = 0
    for i in range(n - 1):              # 席位：0 到 n-2（最后一个自动就位）
        best = i                        # 先假设坐在 i 席的就是最小
        for j in range(i + 1, n):       # 后面的选手逐个上台挑战
            compares = compares + 1
            if roster[j] < roster[best]:
                best = j                # 打赢了，换擂主（记位置，先不搬人！）
        if best != i:                   # 一轮打完，才真正交换一次
            temp = roster[i]
            roster[i] = roster[best]
            roster[best] = temp
    return compares

prey = ["vole", "sparrow", "mouse", "squirrel", "rabbit", "fish"]
steps = selection_sort(prey)
print(prey)     # 先猜顺序，再跑
print("比较次数:", steps)
```

**先猜两个输出再跑**：排好的顺序 + 比较次数。

注意一个细节（笔试爱考）：擂台赛中 `best = j` 只**记位置**不搬人，整轮结束才交换**一次**——这就是"选择"二字的含义：先选后换。

### 嵌套循环 = 步数会"面积式"涨

外圈 n-1 轮，每轮内圈越来越少（n-1、n-2、…、1），加起来：

**n × (n − 1) ÷ 2，也就是 1 + 2 + … + (n−1)**

6 项 = 15 次（和你跑出来的数对上了吗？）。

## 四、步数会怎么涨（5 分钟）

把加餐①的表格请回来对比（那张表的孪生兄弟）：

| 名册大小 | 逐个比较（选择排序） | 每次砍半（二分查找） |
|---|---|---|
| 6 | 15 次 | 3 次 |
| 100 | 4,950 次 | 7 次 |
| 1,000 | 499,500 次 | 10 次 |
| 1,000,000 | 约 5 亿次 | 20 次 |

选择排序的步数像**正方形面积**一样涨（n 翻倍，步数×4）；二分是砍半，几乎不涨。**排序 100 万项要 5 亿次比较**——听起来该绝望了？别慌：寒假算法正篇登场"快速排序"，100 万项只要约 2000 万次——**分治 + 递归**（加餐②的地基）砍出来的快刀。今天先把台阶站稳。

## 六、练习答案（先做再看！）

**1.** `['fish', 'mouse', 'rabbit', 'sparrow', 'squirrel', 'vole']`，比较次数 15。

**2.** 第 0 轮：擂台扫 j=1（1<3，best=1）、j=2（2>1），最小是 1 → **a[0] 和 a[1] 交换** → `[1, 3, 2]`。第 1 轮：j=2（2<3，best=2）→ **a[1] 和 a[2] 交换** → `[1, 2, 3]`。共交换 **2 次**。

**3.** 比较次数和内容无关，只和长度有关：3 项 = 3 次；但完全倒序时**每轮都要交换**（每轮的最小都在后面），交换 **2 次**。规律：交换次数 ≤ n-1，这就是"先选后换"省下来的搬运费（想想链表插队要挪多少人）。

**4.** 只改一个字符：`roster[j] < roster[best]` → `roster[j] > roster[best]`（擂台改比谁更大）。

**5.** 提示：

```python
def sorted_pretty(roster):
    copy = roster[:]           # 切片复制一份（W06），别改人家原册
    selection_sort(copy)
    return "-".join(copy)
```

排序前后 `len()` 都是 6——**原地排序不添不减**。

## 七、🤖 AI 常识胶囊 · 第 9 颗：数据的坑——AI 也会"偏心"（4 分钟）

> 今天的课说：**名册本身怎么样，排出来就怎么样**——排序算法很老实，但名册会骗人。AI 更是：**它只认训练数据（伙食）**，伙食偏了，它就偏。

两个真实的坑：

- **偏见**：训练照片里清一色家猫，AI 就可能把豹子也认成"大号家猫"——不是它笨，是它没见过。数据里没有的，它学不会。
- **幸存者偏差**：2026 年 AI 营笔试真题改编——"AI 漏检的数据被直接删掉，评测指标会不会看起来变好？"会！把 AI 做错的题从考试里删掉，正确率**数字**当然涨，但它**真实水平**一点没变——被删掉的错题就像"失踪的 rabbit"，不在名册上不等于不存在。

**⚔️ 判一判（先自己答，再看答案）**

1. 训练数据里从没出现过狗，AI 也一样能认对狗。
2. 把 AI 做错的题从评测集里删掉，AI 的真实水平就提高了。

**答案**：1 ✗（没吃过的伙食长不出那个本事——数据决定能力边界）；2 ✓ 还是 ✗？——**✗**！提高的只是**指标数字**（幸存者偏差），真实水平纹丝不动。评 AI、评人都一样：**先问一句"名册完整吗"**。

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天的选择排序，C++ 长这样（和 Python 逐行对得上）：

```cpp
#include <iostream>
int main() {
    int a[5] = {5, 2, 8, 1, 4};                     // 认脸①：数组一次造好（上节课的格子间）
    for (int i = 0; i < 4; i++)                     // 认脸②：外圈席位
        for (int j = i + 1; j < 5; j++)             // 认脸③：内圈擂台
            if (a[j] < a[i]) { int t = a[i]; a[i] = a[j]; a[j] = t; }  // 认脸④：空杯舞压成一行
    std::cout << a[0] << a[1] << a[2] << a[3] << a[4];
    return 0;
}
```

认脸要点：`int a[5]`（造 5 格）、`for (int i = 0; i < 4; i++)`（分号隔三段）、交换三步。这张脸和递归脸一样，**笔试年年见**。（小心：这版是"边打边换"，和 Python 版"先选后换"细节不同，思想一样。）
