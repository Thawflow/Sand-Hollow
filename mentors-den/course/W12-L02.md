## 一、概念：电脑对战玩家的经典游戏（5 分钟）

石头剪刀布 = 玩家出拳 + 电脑随机出拳 → 比大小决定胜负。

**游戏规则：**

- 石头 > 剪刀
- 剪刀 > 布
- 布 > 石头
- 相同 = 平局

## 二、第一版（10 分钟）

新建 `rps.py`：

```python
import random

print("=== Rock Paper Scissors ===")
choices = ["rock", "paper", "scissors"]

player = input("Your choice (rock/paper/scissors): ").strip().lower()
computer = random.choice(choices)

print(f"You: {player}, Computer: {computer}")

if player == computer:
    print("Tie!")
elif (player == "rock" and computer == "scissors") or \
     (player == "scissors" and computer == "paper") or \
     (player == "paper" and computer == "rock"):
    print("You win!")
else:
    print("Computer wins!")
```

## 三、第二版：多局 + 计分（10 分钟）

```python
import random

print("=== Rock Paper Scissors · Best of 5 ===")
choices = ["rock", "paper", "scissors"]
player_score = 0
computer_score = 0

for round in range(1, 6):
    print(f"\n--- Round {round} ---")
    player = input("Your choice: ").strip().lower()
    computer = random.choice(choices)
    print(f"You: {player}, Computer: {computer}")

    if player == computer:
        print("Tie!")
    elif (player == "rock" and computer == "scissors") or \
         (player == "scissors" and computer == "paper") or \
         (player == "paper" and computer == "rock"):
        print("You win this round!")
        player_score += 1
    else:
        print("Computer wins this round!")
        computer_score += 1

print(f"\n=== Final Score ===")
print(f"You: {player_score}, Computer: {computer_score}")
if player_score > computer_score:
    print("You won the match!")
elif player_score < computer_score:
    print("Computer won the match!")
else:
    print("It's a tie overall!")
```

## 四、第三版：用字典简化判定（10 分钟）

石头剪刀布的胜负关系可以用字典表示：

```python
# Key beats Value
beats = {
    "rock": "scissors",
    "scissors": "paper",
    "paper": "rock",
}

# Determine winner
if player == computer:
    result = "tie"
elif beats[player] == computer:
    result = "win"
else:
    result = "lose"
```

**解读：** `beats[player]` 存的是 player **能打败**的对手——所以 `beats[player] == computer` 成立时，computer 正好是 player 的手下败将，player 赢。

## 六、⚠️ 新手三大坑（5 分钟）
