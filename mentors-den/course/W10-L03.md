## 二、画正多边形家族（10 分钟）

新建 `poly_family.py`：

```python
import turtle

t = turtle.Turtle()
t.speed(0)

def polygon(sides, length):
    angle = 360 / sides
    for i in range(sides):
        t.forward(length)
        t.left(angle)

# Draw multiple polygons
for shape in range(3, 8):
    polygon(shape, 80)
    t.penup()
    t.forward(120)
    t.pendown()
```

跑出 5 个形状：三角形 → 正方形 → 五边形 → 六边形 → 七边形。**每个用 polygon 函数画**。

## 三、画雪花（15 分钟）

需求：6 条线，每条线由 5 个小段组成，每段画完转一个小角度。

```python
import turtle

t = turtle.Turtle()
t.speed(0)

def snowflake_arm():
    for i in range(5):
        t.forward(30)
        t.backward(30)
        t.left(60)  # branch out

# 6 arms at 60-degree spacing
for arm in range(6):
    snowflake_arm()
    t.left(60)
```

**理解技巧：**

- 一个 arm = 5 个「前进 30 + 后退 30 + 左转 60」的小段
- 每个 arm 整体转 60°，6 个 arm 转完 360° = 一个雪花

## 四、画螺旋（10 分钟）

需求：边长递增 + 转固定角度，画出螺旋线。

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pencolor("blue")

# Length grows by 5 each step
for i in range(30):
    t.forward(5 + i * 5)
    t.left(91)  # slightly off 90 = spiral (not square)
```

**关键观察：** 转 90° = 正方形累加（看起来像方框）；转 91° = 螺旋线（因为每步偏 1°，30 步 = 偏 30° = 螺旋）。

## 五、综合：画一面彩旗（10 分钟）

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(3)

# Background: 3 colored bands
colors = ["red", "white", "blue"]
band_height = 60
for color in colors:
    t.fillcolor(color)
    t.begin_fill()
    for i in range(2):
        t.forward(150)
        t.left(90)
        t.forward(band_height)
        t.left(90)
    t.end_fill()
    t.penup()
    t.left(90)
    t.forward(band_height)
    t.right(90)
    t.pendown()
```

跑出法国/俄罗斯/荷兰风格的彩旗。**关键技巧：** 每画一格后 penup 移位，pendown 继续。
