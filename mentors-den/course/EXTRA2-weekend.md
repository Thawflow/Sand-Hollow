## 一、本周武功盘点（3 分钟）

- **递归三要素**：基线 / 调用自己 / 越走越近基线
- **汉诺塔**：搬 n 片 = 搬 n-1 + 搬 1 + 搬 n-1，最少 2ⁿ - 1 步
- **分形树**：每个分叉长两棵小树，depth 每加 1，树枝数翻倍

这周起，"函数"在你手里不只会打包功夫，还会**自我复制地干活**——这是算法正篇"分治"的地基。

## 二、项目 A：分形画廊（25 分钟）

把 EXTRA2-L02 的分形树改出**至少 3 幅作品**，办一个画廊。每幅改一组参数：

| 作品编号 | 改什么 | 例子 |
|---|---|---|
| ① 瘦高树 | 两处角度改小 | `left(15)` / `right(30)` |
| ② 张开树 | 两处角度改大 | `left(45)` / `right(90)` |
| ③ 密林 | depth 加大 | `depth = 6` |

每幅画完**截图存档**（文件名 `fractal-1.png` 这样），并在练习文件里写两行注释：改了什么 / 树形变成什么样。

**观察记录表**（跟着填，是今天的核心练习）：

| depth | 树枝总数（分叉点数） | 画起来快不快 |
|---|---|---|
| 2 | 3 | 眨眼间 |
| 3 | 7 | 很快 |
| 4 | 15 | 快 |
| 5 | ？ | ？ |
| 6 | ？ | ？ |

树枝数就是汉诺塔步数的公式——**2ᵈᵉᵖᵗʰ - 1**。depth = 10 时是 1023 根，画面已经要等一会儿了：递归翻倍，先甜后苦。

## 三、项目 B：汉诺塔 4 层挑战（15 分钟）

1. 手玩 4 片汉诺塔（4 枚硬币），目标 **15 步**以内完成——亲手体会"翻倍"的分量
2. 卡住了就打开代码 `hanoi(4, "A", "B", "C")`，**照着它打印的步骤搬**——让递归当你的教练
3. 挑战成功后回答：5 片要多少步？你**还愿意手玩吗**？（答案：31 步；不愿意就对了——这就是算法存在的意义）

## 四、讲给家人听（10 分钟，本周最重要的一环）

把站队问题演给家人看：全家排队，每个人**只能问前面一个人**"你排第几"，排头回答"我第 1"，答案传回来。

演完讲清三件事（费曼式，讲不明白就是没真懂）：

2. 为什么每个人做的事一模一样（自己调用自己）

## 五、🤖 AI 常识胶囊 · 第 7 颗：提示词——跟 AI 说话的咒语（4 分钟）

> 这两周你调了两次 AI 吗？同一个 AI，**问法不同，答案质量天差地别**。把话说清楚的本事，行话叫**提示词（prompt）**。

好咒语三件套（和 W02 跟电脑对话、W08 写函数的思路是通的）：

1. **角色**：「你是一位 Python 老师」
2. **任务**：「用递归解释汉诺塔怎么解」
3. **要求**：「我 12 岁，只学过函数和循环，请不超过 5 句话」

对比差咒语：「汉诺塔咋整」——AI 会端出一锅成人味的浓汤。

**⚔️ 判一判（先自己答，再看答案）**

1. 同一个问题，问法不同，AI 的回答质量可能差很多。
2. 提示词是程序员才能用的特殊密码，普通人学不会。

**答案**：1 ✓（把角色、任务、要求说清楚，就是普通人最强的提示词）；2 ✗（说人话的三件套，谁都能学会——你已经会了）。

## 六、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天认一张新脸：**void**——"什么都不还"的函数（Python 里只 print 不 return 的那种）：

```cpp
#include <iostream>
void count(int n) {              // 认脸①：void = 空手而归，不用 return 值
    if (n == 0) return;          // 认脸②：直接 return = 只管撤退，不交东西
    std::cout << n << " ";
    count(n - 1);                // 认脸③：递归倒计时，老朋友了
}
int main() {
    count(5);                    // 5 4 3 2 1
    return 0;
}
```
