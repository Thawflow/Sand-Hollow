## 一、四件套一次看全（5 分钟）

```python
cat = {"name": "Whiskers", "age": 3}

cat["color"] = "tabby"     # 增：新键赋值
print(cat["name"])         # 查：键取值
cat["age"] = 4             # 改：老键重新赋值
del cat["color"]           # 删：del + 键
print(cat)
```

| 动作 | 写法 | 一句话 |
|---|---|---|
| 增 | `cat["color"] = "tabby"` | 键不存在 → 新添一对 |
| 查 | `cat["name"]` | 报名字，拿东西 |
| 改 | `cat["age"] = 4` | 键已存在 → 覆盖旧值 |
| 删 | `del cat["color"]` | 整对搬走 |

**增和改是同一招**：`字典[键] = 值`——键不存在就是增，存在就是改。Python 自己会看。

## 二、in：查岗再进门（3 分钟）

查一个**不存在的键**会 KeyError 摔门。礼貌的做法是先敲门：

```python
contacts = {"Alice": "13800138001", "Bob": "13800138002"}

name = input("Name to look up: ")
if name in contacts:
    print(f"{name}'s number: {contacts[name]}")
else:
    print(f"{name} not in contacts")
```

`in` 检查键在不在，返回 True / False（W03 的布尔值又上岗了）。**凡是查别人输入的键，先 in 后取**——这是字典世界的安检门。

## 三、小坑两枚（2 分钟）

```text
cat = {"name": "Whiskers", "age": 3}
cat = {}        # ❌ 这是「换了个新空字典」，不是清空原字典
```

`cat = {}` 是**新建**一个空字典贴上旧名字，原来的档案被整个扔掉（想清空原字典用 `cat.clear()`，混个脸熟）。

另一枚：改值写成 `cat = {"age": 4}` 以为「只改年龄」——错，这同样是**整个换新**。改一个键，用 `cat["age"] = 4`。
