## 一、比较运算符六兄弟（5 分钟）

if 的"条件"靠它们写出来：

| 写法 | 读作 | 例子 | 结果 |
|---|---|---|---|
| `==` | 等于 | `10 == 10` | True |
| `!=` | 不等于 | `"猫" != "狗"` | True |
| `>` | 大于 | `3 > 5` | False |
| `<` | 小于 | `3 < 5` | True |
| `>=` | 大于等于 | `60 >= 60` | True |
| `<=` | 小于等于 | `59 >= 60` | False |

比较的结果是 **True / False**（真 / 假），这类值叫**布尔值**——今天混个脸熟，后面天天见。

**透视镜时刻（W02 的知识回来了）：**

```python
print("10" == 10)   # False！
```

字符串 `"10"` 和数字 `10` 类型不同，Python 眼里**永不相等**。引号是种族标志，忘了的回 W02-S1 翻口诀。

## 二、缩进即语法（5 分钟）

别的语言用花括号 `{}` 圈地盘，Python 用**缩进**。看这段：

```python
score = 59
if score >= 60:
    print("Passed!")
print("Done!")
```

最后一行**没缩进**——它不属于 if，不管及不及格都会打印。

- 运行：if 内部跳过，但 "Done!" 照样出现
- 缩进与否，改变每一行的归属

这就是「**缩进即语法**」：缩进不是美观，是规则本身。

## 三、Thonny 缩进小贴士（1 分钟）

写完 `if ...:` 按回车，光标自动缩进；想退出缩进，按一次删除键。Thonny 在帮你守规矩。

**今日口诀：** 六兄弟比出真假，缩进决定谁听谁的。
