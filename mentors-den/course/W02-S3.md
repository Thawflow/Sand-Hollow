## 一、概念：字符串是字符项链（3 分钟）

`"ThawPaw"` 想象成一条项链，每个字符是一颗珠子：

```
T-h-a-w-P-a-w   （7 颗珠子，从 0 开始编号！）
0-1-2-3-4-5-6
```

**编号从 0 开始**是编程世界的铁律——第一颗珠子是 0 号，不是 1 号。

## 二、四招基本功（6 分钟）

```python
name = "ThawPaw"

len(name)          # 7      —— 数珠子（长度）
name.upper()       # THAWPAW —— 全变大写
name.lower()       # thawpaw —— 全变小写
name.count("a")    # 2      —— 数某个字符出现几次
```

四招都是**项链自带技能**（专业说法叫「方法 method」）：`数据.技能()` 的句式——`name.upper()` 读作「name，变大声！」😼

## 三、replace：偷天换日（4 分钟）

```python
msg = "I like dogs"
msg.replace("dogs", "cats")   # "I like cats"
```

把项链里所有的 `dogs` 珠子串换成 `cats`。一次换所有出现的位置：

```python
"aabbcc".replace("b", "x")   # "aaxxcc" —— 两个 b 都换了
```

**注意：** replace 不改原项链，是返回一条新的。想留住结果要装进盒子：

```python
new_msg = msg.replace("dogs", "cats")   # ✅ 结果存进 new_msg
```
