## 一、概念：玩家得有「状态」（5 分钟）

光有地图不够。玩家在游戏里得有：

- HP（生命值）
- 攻击 / 防御
- 道具栏

这些数据叫**玩家状态**。整个游戏过程都在读写这些数据——走路不变，战斗会扣血，捡道具会加属性。

**今天的目标：** 加一个字典存玩家状态 + 一个简单的「遇到敌人 → 战斗或逃跑」机制。

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `player = {...}` | **字典**（W10 详细学）：键-值对存状态 |
| `"hp": 100` | HP = 100 |
| `"inventory": []` | 道具栏 = 空列表 |

**字典**用花括号 `{}`，键-值对用 `:` 分隔，多对用 `,` 隔开。**W06 学的列表是 [值, 值]，字典是 {键: 值, 键: 值}**。

读值用 `player["hp"]`（中括号 + 字符串键）。

## 三、战斗雏形（15 分钟）

```python
enemies = {
    "wolf": {"name": "Gray Wolf", "hp": 30, "attack": 8, "defense": 2},
    "eagle": {"name": "Giant Eagle", "hp": 80, "attack": 15, "defense": 8},
}

def battle(player, enemy):
    print(f"\nA wild {enemy['name']} appears!")
    print(f"  HP {enemy['hp']} / ATK {enemy['attack']} / DEF {enemy['defense']}")

    while enemy["hp"] > 0 and player["hp"] > 0:
        action = input("\n(attack/run): ").strip()
        if action == "run":
            print("You escaped!")
            return True

        # Player attacks
        dmg = max(1, player["attack"] - enemy["defense"])
        enemy["hp"] -= dmg
        print(f"You hit {enemy['name']} for {dmg} damage. Enemy HP: {enemy['hp']}")

        if enemy["hp"] <= 0:
            print(f"You defeated {enemy['name']}!")
            return True

        # Enemy attacks back
        dmg = max(1, enemy["attack"] - player["defense"])
        player["hp"] -= dmg
        print(f"{enemy['name']} hits you for {dmg}. Your HP: {player['hp']}")

        if player["hp"] <= 0:
            print("You have fallen...")
            return False
```

### 拆解

- **`enemies` 字典**：每个敌人有自己的 HP/ATK/DEF
- **`def battle(...)`**：**函数**（W08 详细学），今天先用
- **伤害公式**：`max(1, ATK - DEF)`：至少扣 1 点血，不会 0 伤害
- **战斗循环**：while 双方都活着，每回合玩家攻击 → 敌人攻击
- **`return True/False`**：返回战斗结果（True = 玩家活下来）

## 四、接到地图里（5 分钟）

在 L1 的 `forest` 房间加入战斗（贴到主循环 while 里）：

```python
# Inside the main while loop:
if room == "shrine":
    # ... shrine choices ...
    pass
elif room == "forest":
    print("\n--- Whispering Forest ---")
    print("Tall trees rustle around you. A wolf blocks your path.")
    choice = input("(fight/run): ")
    if choice == "fight":
        won = battle(player, enemies["wolf"])
        if not won:
            room = "game_over"
        else:
            print("Forest path is now clear.")
            room = "shrine"
    elif choice == "run":
        room = "shrine"
```

`if not won: room = "game_over"` —— **战斗输了跳到游戏结束分支**。

## 五、加一个 game_over 房间（5 分钟）

```python
# Add to the main while loop (continuation):
if room == "game_over":
    print("\n=== GAME OVER ===")
    print(f"You fell at the {player['name']}'s journey.")
    print("Better luck next time!")
    room = "quit"
```

只要玩家血量归 0，剧情就走这里，然后 `while` 条件不满足退出。
