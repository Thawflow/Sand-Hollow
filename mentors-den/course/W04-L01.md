## 一、概念：程序终于学会「重复」（5 分钟）

前三周我们的程序都是「直线剧本」——从第一行演到最后一行，每行只做一次。

但很多事是重复的：

- 战士训练每天做 100 个俯卧撑
- 商店货架每天补 30 件商品
- 妈妈记账时数 12 个月的开销

**for 循环**就是让程序学会「把同一件事做 N 遍」的本领。今天这一招，是后面所有自动化程序的起点。

## 二、for 的样子（8 分钟）

新建 `first_for.py`，亲手敲：

```python
for i in range(5):
    print("Hello,", i)
```

运行看输出：

```
Hello, 0
Hello, 1
Hello, 2
Hello, 3
Hello, 4
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `for` | 「为了」每个值，做下面这些事 |
| `i` | 临时变量（i = iteration，迭代），每次循环换一个新值 |
| `in range(5)` | 从 0、1、2、3、4 一共 5 个数字里逐个取出来 |
| `:` | 冒号 =「那么」，下面缩进的行归它管 |
| 缩进 | 手下名单：每次循环都跑一遍 |

**关键观察：** `i` 从 0 开始，不是 1。这是程序员的传统（很多语言都这样），记住就好。

## 三、range 的三种玩法（10 分钟）

`range` 是 for 循环的最佳搭档，三种姿势：

```python
# Form 1: range(5) gives 0,1,2,3,4 (start from 0, up to N-1)
for i in range(5):
    print(i)

# Form 2: range(2, 7) gives 2,3,4,5,6 (start at 2, stop BEFORE 7)
for i in range(2, 7):
    print(i)

# Form 3: range(0, 10, 2) gives 0,2,4,6,8 (step 2 = skip every other)
for i in range(0, 10, 2):
    print(i)
```

Shell 里亲手试一次：

```python
>>> list(range(5))
>>> list(range(1, 6))
>>> list(range(0, 20, 5))
```

`list(...)` 是把 range 变成列表打印出来—— range 自己是「会生蛋的鸡」，不打印就看不到全部。

**记忆口诀（自创版，可改）：**

> 单个 N 算尾巴，**不含 N 永远差一**
> 两个 a b 是范围，**含头不含尾**
> 三个加步长，**跳着走也能到**

## 四、用循环做点有用的（5 分钟）

光打数字不过瘾，做两个真正的小事：

### 4.1 数到 10 关电视

```python
for second in range(1, 11):
    print(second, "...")
print("Time's up! Turn off the TV")
```

`second` 比 `i` 更贴切——这是变量命名的好处，**让人读代码就知道在干嘛**。

### 4.2 9 的乘法表前 9 项

```python
for n in range(1, 10):
    print(f"9 x {n} = {9 * n}")
```

f-string 拼一行，循环打 9 行——W02-L03 的 f-string 立刻派上用场。

## 五、⚠️ 新手三大坑（5 分钟）

1. **缩进忽长忽短**：跟 if 一样，循环体内的行必须统一缩进（4 空格）。一格错就 IndentationError。
2. **range 末尾不含**：`range(5)` 给的是 0-4，不是 0-5。**「含头不含尾」**是 range 唯一铁律。
3. **漏冒号**：`for i in range(5)` 少了 `:` → SyntaxError。

老规矩：三个坑各故意踩一次，读报错最后一行，再修好。
