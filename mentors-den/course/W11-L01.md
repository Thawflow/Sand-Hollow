## 一、概念：程序要有「运气」（5 分钟）

之前所有程序都是「确定」的——同样输入给同样输出。但很多场景需要「随机」：

- 游戏：敌人出现、宝物掉落
- 抽奖：从候选里抽一个
- 测试：生成随机数据
- 加密：随机密码

Python 的 `random` 模块提供这些能力。

## 二、random 的基本用法（10 分钟）

新建 `first_random.py`，亲手敲：

```python
import random

# Random integer
print(random.randint(1, 10))  # 1-10 inclusive

# Random choice from list
fruits = ["apple", "banana", "cherry"]
print(random.choice(fruits))

# Random float 0-1
print(random.random())

# Shuffle
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)
print(cards)
```

多 Run 几次看，每次输出都不一样。

### 逐字拆解

| 命令 | 作用 | 例子 |
|---|---|---|
| `random.randint(a, b)` | a 到 b 的整数（含两头） | `randint(1, 6)` = 1-6 |
| `random.choice(list)` | 从列表随机抽一个 | `choice(fruits)` |
| `random.random()` | 0.0 到 1.0 的浮点数 | 0.7321... |
| `random.shuffle(list)` | 随机打乱列表 | 直接改原列表 |

**关键：** `random.randint(1, 10)` **两头都包含**（跟 range(1, 11) 行为不一样，要小心）。

## 四、实战：随机密码生成器（10 分钟）

```python
import random
import string

length = int(input("Password length: "))

chars = string.ascii_letters + string.digits
# ascii_letters = a-z + A-Z, digits = 0-9

password = ""
for i in range(length):
    password += random.choice(chars)

print(f"Generated password: {password}")
```

`string.ascii_letters` 是 `string` 模块提供的「所有字母字符串」，`string.digits` 是「所有数字字符串」。

## 五、实战：抽签（7 分钟）

```python
import random

names = ["Alice", "Bob", "Charlie", "Diana", "Eve"]
winner = random.choice(names)
print(f"Winner: {winner}!")
```

或者多抽几个不重复：

```python
# Pick 3 unique winners
winners = random.sample(names, 3)
print(f"Winners: {', '.join(winners)}")
```

`random.sample(list, n)`：从列表抽 n 个**不重复**的元素。

## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）

C++ 的骰子（老写法）：

```cpp
#include <cstdlib>
srand(time(0));            // 用时间播种
int dice = rand() % 6 + 1; // %6 → 0~5，+1 → 1~6
cout << dice;
```

- **认脸①**：取余 % + 1 的技巧和 Python 版思路相同
- **认脸②**：srand 播种 = Python random.seed 的老亲戚
