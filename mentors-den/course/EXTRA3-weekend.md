## 二、项目 A：排序运动会（20 分钟）

### 纸牌版（全家可玩）

拿数字卡 1-9 打乱摆一行。你当"排序算法"：

1. 第 0 轮：扫全排，找最小 → **换**到 0 号位（大声报"比较 8 次，交换 1 次"）
2. 第 1 轮：从 1 号位往后扫……直到全排有序
3. 全程记录**总比较次数**——9 张卡应该正好 36 次（8+7+6+…+1），对不上就重玩

家人可以当"裁判"报数，你当"算法"动手。谁快谁慢不重要，**报数准确**才重要。

### 代码版（加秒表）

```python
import time
import random

def selection_sort(roster):
    n = len(roster)
    for i in range(n - 1):
        best = i
        for j in range(i + 1, n):
            if roster[j] < roster[best]:
                best = j
        if best != i:
            temp = roster[i]; roster[i] = roster[best]; roster[best] = temp

for size in [100, 500, 1000]:
    data = list(range(size))
    random.shuffle(data)          # W11 的老朋友 random 提前来热身
    start = time.time()
    selection_sort(data)
    print(size, "项用时", round(time.time() - start, 3), "秒")
```

    for i in range(len(times)):

## 五、🤖 AI 常识胶囊 · 第 10 颗：多模态——会看会听的 AI（3 分钟）

> 排序运动会的纸牌版，是"动手"版；代码版，是"动键盘"版——**同一种信息，不同的载体**。AI 圈也在干这件事：**多模态（multimodal）** = 一个 AI 同时吃多种载体：文字 + 图片 + 声音 + 视频。

见过的世面：

- 你发一张数学题**照片**，AI 直接读题讲解（认图）

只用文字聊天的传统大模型是"单模态"；今天的一线选手（包括 DeepSeek 系、GPT 系、通义系）大多在往多模态进化——**眼睛和耳朵，正在长到模型身上**。

## 六、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天认"打擂台找最大"的脸（和第三题调度题是近亲）：

```cpp
#include <iostream>
int main() {
    int a[6] = {3, 9, 1, 7, 4, 6};
    int best = 0;                      // 认脸①：先假设 0 号是擂主（记位置！）
    for (int i = 1; i < 6; i++)        // 认脸②：后面的逐个上台
        if (a[i] > a[best]) best = i;  // 认脸③：打赢只换座牌，不搬人
    std::cout << "最大 " << a[best] << " 在第 " << best << " 格";
    return 0;
}
```

认脸要点：`best` 存**位置**不存值——和选择排序的擂台一模一样。`a[best]` 才是值。
