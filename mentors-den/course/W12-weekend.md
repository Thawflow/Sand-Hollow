## 一、本周回顾（3 分钟）

- W12-L02：逐块实现 + 跑通
- W12-L03：作品说明 + 家族展示

今天是毕业展——**正式向家人完整演示 + 庆祝**。

## 二、毕业展流程（60 分钟）

### 第一段：5 分钟自我介绍 + 项目概述

讲三件事：

1. 这是什么（功能 + 解决的问题）
2. 我怎么做的（设计图 → 逐块 → 跑通）
3. 我学到了什么（最大收获 + 还想改进）

### 第二段：10 分钟现场演示

完整跑一遍项目：

- 启动 → 主菜单 → 核心功能 → 保存 → 退出 → 重启看加载
- **故意出错一次**（如输入无效值），展示程序怎么应对
- **展示一个亮点**（最让你自豪的部分）

### 第三段：5 分钟家人上手

让家人自己试一遍，看他们能不能独立完成一个核心任务。

### 第四段：10 分钟反馈 + 改进

让家人说：

- 哪里不清楚？
- 哪里做得好？
- 哪里想改？

**当场改 2-3 处**，展示你能「听完即改」。

### 第五段：5 分钟庆祝 🎉

毕业了！给自己和家人一个庆祝仪式：

- 拍一张你和家人的合影
- 把作品 git commit 一笔：「毕业项目 v1.0」
- 写一句话给未来的自己（保存到 `life/`）

## 五、🎓 毕业赠言

12 周前你连 print 都不会，现在你能做一个完整作品给别人用。这中间的每个 print、每个 for、每个 bug、每个 fix，都是你自己的。

Python 是个工具，但**学会「拆解问题 → 写代码 → 测试 → 改进」这套思维**，比 Python 本身更重要。

接下来你可以选：

- **Web 开发**（Flask / Django）—— 做网站

- **AI / 机器学习**（scikit-learn）—— 让程序学
- **自动化脚本**—— 解放双手

**任何方向，方法都一样**：拆解 + 写 + 测 + 改。
