## 一、概念：循环真正的威力（5 分钟）

上节课我们用 for 循环打了 5 行 `Hello`，看着像玩具。**for 循环真正的威力是「累加」**——把一堆数压成一个数。

- 妈妈数你这个月花了多少钱（10 笔加一起）
- 老师算全班平均分（30 个分数加一起再除以 30）
- 商店盘点库存（50 件商品数件数）

这节课学一招叫**累加器模式**——记住四个字：「先建箱子，再循环里往里扔」。

## 二、第一招：求和（8 分钟）

新建 `sum_basics.py`，亲手敲：

```python
# Sum numbers from 1 to 10
total = 0
for i in range(1, 11):
    total = total + i
print("Sum 1-10 =", total)
```

运行得 `Sum 1-10 = 55`（高斯小时候的故事，7 岁就算出来过，你也不差）。

### 逐字拆解「累加器四件套」

| 部件 | 作用 |
|---|---|
| `total = 0` | **建箱子**：起手 0 个（累加器必须先归零） |
| `for i in range(1, 11)` | 循环：逐个取出 1 到 10 |
| `total = total + i` | **往里扔**：把当前数字加进箱子 |
| `print(...)` | **出箱子**：循环结束，打印结果 |

`total = total + i` 看着像「自己等于自己」，但 Python 是**先算右边，再装进左边**——右边的 total 是「老总和」，左边的 total 是「装上新值的箱子」。每轮循环，箱子长大一圈。

**简短写法：** `total += i` 等价于 `total = total + i`，以后常用。

### Shell 里追踪一遍

```python
>>> total = 0
>>> total = total + 3
>>> total
3
>>> total = total + 5
>>> total
8
```

一步一步看清箱子长大的过程。

## 三、第二招：计数（7 分钟）

求和是把数字加进去。**计数是把 1 加进去**——每看到一个目标，箱子 +1。

```python
# Count how many "even" numbers in 1-20
count = 0
for i in range(1, 21):
    if i % 2 == 0:
        count = count + 1
print("Even numbers in 1-20:", count)
```

`i % 2 == 0` 判断 i 是偶数（除以 2 余 0，W02-L01 知识）。**% 是「取余数」**，混个脸熟，下节课正式开。

### 拆解

- `count = 0`：建一个空计数器
- `if i % 2 == 0`：是偶数吗？
- `count = count + 1`：是的话，计数器 +1
- 最后打印：1-20 一共多少个偶数

简短写法：`count += 1`。

## 四、第三招：找最大（10 分钟）

最复杂的累加器——不是把所有数加起来，而是**留住最大的那个**。

```python
# Find the largest number in [3, 7, 2, 9, 4]
nums = [3, 7, 2, 9, 4]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print("The biggest is:", biggest)
```

得 `The biggest is: 9`。

### 逐字拆解

- `nums = [3, 7, 2, 9, 4]`：一个列表（W06 正式学，今天先借用）
- `biggest = nums[0]`：把「第一个数」当成当前最大
- `for n in nums`：逐个取出来比
- `if n > biggest`：发现更大的？
- `biggest = n`：是的话，换人当擂主
- 最后打印：擂主就是最大

**注意 `nums[0]` 是列表里的第 1 个数**（0 是 Python 的「第 1 个」）。这个细节 W06 还会回来讲，今天只要知道「先把第一个当成擂主」就行。

## 五、⚠️ 新手三大坑（5 分钟）

1. **忘建箱子**：`for i in range(5): total = total + i` 但 total 没先建 → `NameError: name 'total' is not defined`。**累加器必须先建再循环。**
2. **建错初值**：找最大却 `biggest = 0`，列表里全是负数时全军覆没（最大负数比 0 小，但 0 不是列表里的数）。**找最大初值 = 第一个数；找最小 = 第一个数；求和 = 0；计数 = 0。**
3. **`=` 与 `==` 混淆**：`if n = biggest:` 又是 SyntaxError。比较用 `==`，赋值用 `=`。

老规矩：三个坑各故意踩一次，读报错最后一行，再修好。
