## 一、先玩一个站队问题（5 分钟）

猫武士集合巡逻队，排成一条长队。族长想知道：**你排第几位？**

规则很苛刻：不许回头数，**只能问紧挨着你前面的那只猫**。

你会怎么办？——只能这样：

1. 你问前面一只：「你排第几？」
2. 他也不知道，只好**再问他前面那只**……
3. 一路问到**排头**，排头终于能回答：「我第 1。」
4. 然后答案**一层一层传回来**：第 2、第 3……直到你。

发现了吗？**"问前面"这个动作在原地打转——问着问着，问题自己变小了（队伍越来越短），最后撞上一个能直接回答的人。**

这就是递归（recursion）：**一个函数，在自己的身体里再调用自己。**

## 二、递归三要素（5 分钟）

写递归之前先背三句话，缺一句就翻车：

1. **基线条件**：什么时候停？——排头说"我第 1"，就是基线。
2. **自己调用自己**：函数体内出现自己的名字——你问前面那只。
3. **每一步都更靠近基线**：队伍每次短一截。——如果越问队伍越长，永远问不完。

反例现场：套娃如果不设"最小那个是实心的"，你将永远拆下去。Python 也一样——递归不收敛，它会当场罢工：

```python
def boom():
    boom()      # 没有基线，自己调用自己，永不停

boom()          # RecursionError: maximum recursion depth exceeded
```

亲眼跑一次（**先猜报不报错，再跑**——圈题面规矩）：猜对的在练习本上给自己画个 ⭐。

## 三、动手：倒计时与阶乘（15 分钟）

### 倒计时 rocket（最短递归）

```python
def countdown(n):
    if n == 0:              # 基线：数到 0 就停
        print("点火！🚀")
        return
    print(n)
    countdown(n - 1)        # 自己调用自己，问题小一号

countdown(5)
```

先猜输出顺序，再跑。注意：**先 print 再调用**，所以是 5 4 3 2 1 点火。

### 阶乘：部族的乘法链条（5 分钟）

猎物换算规矩：1 只兔子 = 2 根冻鱼干，2 只 = 2×2 根……**n 的阶乘**（写作 `n!`）= 1×2×3×…×n，是算法课的老朋友。

用乘法链条想递归：`5! = 5 × (4!)`，而 `4! = 4 × (3!)`……一直到 `1! = 1`（基线！）。

```python
def factorial(n):
    if n <= 1:              # 基线：1! = 1
        return 1
    return n * factorial(n - 1)   # n! = n × (n-1)!

print(factorial(5))         # 先猜：多少？
```

**先猜再跑**。然后做一个大新闻：把 5 改成 20，`print(factorial(20))`——Python 会算出一个 19 位的大家伙，普通计算器都要冒烟。这叫大数运算，算法正篇还有它的一席之地。

## 六、练习答案（先做再看！）

**1.** `RecursionError: maximum recursion depth exceeded`——Python 替你踩了刹车。

**2.** `3 2 1 点火！🚀`（每行一个数）。

**3.** 变成 `1 2 3 点火！🚀`——先一层层问到底，再一层层**边回头边打印**，顺序整个反过来。这就是"先调用后打印 = 回程做事"。

**4.** factorial(2) 拿到 1 算出 **2**；factorial(3) 拿到 2 算出 **6**；factorial(4) 拿到 6 算出 **24**。跑 `print(factorial(4))` 验证。

**5.** 基线：`if n <= 1: return 1`；递归：`return n + sum_to(n - 1)`。`sum_to(100)` 输出 5050，和高斯小时候的答案一样。

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

> AI 营笔试的编程题用 C++ 出。不用会写，**认得脸**就行：每课课尾放一段和本课同款的 C++，扫一眼混脸熟。

今天的 factorial，C++ 长这样：

```cpp
#include <iostream>
int fact(int n) {              // 认脸①：C++ 函数头要写"还什么类型"（int）
    if (n <= 1) return 1;      // 认脸②：基线在先，和 Python 一模一样
    return n * fact(n - 1);    // 认脸③：函数名出现在自己身体里 = 递归
}
int main() {
    std::cout << fact(5);
    return 0;
}
```

彩蛋：整段没有一个新面孔——**递归不分语言，长哪儿都一样**。认出 `fact` 出现两次，这题的"脸"你就认下了。
