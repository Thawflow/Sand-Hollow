## 一、概念：毕业周到了（2 分钟）

十二周前你连 print 都没写过；今天你手里已经有：循环、判断、列表、字典、函数、random、文件……毕业项目 = 把这些**自己组装成一个完整作品**。

通过标准只有三条：**100+ 行自己写的代码、能讲清每一部分、报错自己修**。不求花哨，求「真是我写的」。

## 二、四类候选项目（5 分钟）

| 项目 | 一句话 | 主要武功 |
|---|---|---|
| 宠物图鉴 v2 | W10 图鉴升级：存档+搜索+战斗 | 字典嵌套 + json |
| RPG 完整版 | W11 骨架加血瓶、Boss、商店 | random + 函数 |
| 猜数字传奇版 | W05 猜数字加难度、排行榜、存档 | 循环 + 文件 |
| 自创主题 | 上面任选一个做底、换皮重设计 | 全部 |

四类的**骨架都是老朋友**——毕业项目不是从零发明，是「选一个最想写完的，把它做到底」。

## 三、决策三问（3 分钟）

拿不准选哪个？依次问自己：

1. **哪个我最想给家人玩？**——动力第一，兴趣撑过五天
2. **哪块我最熟？**——图鉴熟选图鉴、战斗熟选 RPG；毕业周不适合硬啃全新领域
3. **范围砍得动吗？**——先写「最小版」功能清单，砍到 3-4 个功能；「以后再加」的写进清单末尾，不进第一版

第三问最重要：**大项目死于贪心**。5 天 × 25 分钟 + 周末一小时，装 3-4 个功能刚刚好。

## 四、本周路线图（2 分钟）

| 节 | 干什么 |
|---|---|
| S2 | 画设计图：功能 / 数据 / 函数 / 界面 |
| S3 | 最小骨架跑起来 + 做完第一块 |
| S4 | 逐块实现 2-3 块 |
| S5 | save/load + 收尾打磨 |

节奏像族里的作战会议：先定猎物（今天）、再画地盘（S2）、然后逐段巡逻（S3-S5）。每天一小步，周末端出成品。
