## 一、概念：函数接住外部的数据（5 分钟）

函数定义时**挖几个凹槽**，调用时**塞几个值进去**——这就是参数。

```python
def attack(player, enemy):  # two slots
    enemy["hp"] -= player["attack"]

attack(paw, wolf)  # pass paw and wolf in
```

参数让函数「通用」——同一段代码处理不同数据。

## 二、多个参数（8 分钟）

新建 `multi_param.py`，亲手敲：

```python
def introduce(name, age, hobby):
    print(f"I'm {name}, {age} years old.")
    print(f"I like {hobby}.")

introduce("Alice", 12, "drawing")
introduce("Bob", 11, "coding")
```

运行看：每个调用都用三个参数，输出按位置对应。

### 关键：位置参数

**`introduce("Alice", 12, "drawing")` → name="Alice", age=12, hobby="drawing"**

参数按位置一一对应。**位置错就语义错**。

```python
introduce(12, "Alice", "drawing")  # wrong: name=12, age="Alice", hobby="drawing"
```

## 三、关键字参数（8 分钟）

如果不想记顺序，可以**用名字传**：

```python
introduce(hobby="coding", name="Bob", age=11)  # OK
```

`name=` / `age=` / `hobby=` 直接指定值传给哪个凹槽，**顺序无所谓**。

### 混用：位置参数必须在前

```python
# OK
introduce("Alice", 12, hobby="drawing")

# ERROR (commented to keep file valid syntax)
# introduce(name="Alice", 12, "drawing")  # SyntaxError: positional after keyword arg
```

## 四、默认值（8 分钟）

参数可以有默认值——不传就用默认：

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")            # Hello, Alice!
greet("Alice", "Hi")      # Hi, Alice!
greet("Bob", greeting="Hey")  # Hey, Bob!
```

### 实战：菜单函数

```python
def make_coffee(size="medium", sugar=0):
    print(f"Coffee: {size}, sugar: {sugar} spoons")

make_coffee()                # Coffee: medium, sugar: 0 spoons
make_coffee("large")         # Coffee: large, sugar: 0 spoons
make_coffee(sugar=2)         # Coffee: medium, sugar: 2 spoons
make_coffee("small", 3)      # Coffee: small, sugar: 3 spoons
make_coffee("small", sugar=1)  # Coffee: small, sugar: 1 spoons
```

**默认参数让函数更灵活**——常用值不必每次传。

## 五、实战：print_scores 升级（8 分钟）

```python
def print_scores(scores, label="Scores", show_total=True):
    print(f"--- {label} ---")
    for s in scores:
        print(f"- {s}")
    if show_total:
        print(f"Total: {sum(scores)}, Average: {sum(scores)/len(scores):.1f}")

print_scores([85, 92, 78])
print_scores([85, 92, 78], label="Math Test", show_total=False)
```

跑两遍——同一个函数，处理不同 label 和是否显示总分。

## 六、⚠️ 新手三大坑（5 分钟）

1. **参数数量不对**：`greet("Alice", "Bob")` 但函数只接 1 个参数 → TypeError
2. **位置错位**：`attack(wolf, player)` 写反了，运行时按字符串/数字报错（不致命但语义错）
3. **默认参数用 mutable**：`def f(x, lst=[]):` 然后 lst.append(x) → **下次调用 lst 还有上次的数据**。新手期少见，写出来当警示

老规矩：坑 1 时故意多传 / 少传参数看报错。

```python
def calculate(a, b, op="add"):
    if op == "add":
        return a + b
    elif op == "subtract":
        return a - b
    elif op == "multiply":
        return a * b
    elif op == "divide":
        return a / b

print(calculate(10, 5))
print(calculate(10, 5, "multiply"))
```
