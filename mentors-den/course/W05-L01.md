## 一、概念：不知道跑几次才停？（5 分钟）

for 循环很棒，但它有一个前提：**你得先知道跑几次**。

| 场景 | 适合 for？ | 适合 while？ |
|---|---|---|
| 数 1 到 10 | ✅ `for i in range(1, 11)` | 也可以，但繁琐 |
| 画 9 行星星 | ✅ `for i in range(9)` | 也可以 |
| 每天循环到学期结束 | ❌ 不知道几次 | ✅ `while not 学期结束:` |

**while 循环 =「只要条件还成立，就一直跑」**。什么时候停？看条件什么时候变假。

## 二、while 的样子（8 分钟）

新建 `first_while.py`，亲手敲：

```python
n = 1
while n <= 5:
    print(n)
    n = n + 1
print("Done!")
```

运行得：

```
1
2
3
4
5
Done!
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `n = 1` | 起手值 |
| `while n <= 5:` | **条件**：n 小于等于 5 就继续 |
| `print(n)` | 手下活儿 |
| `n = n + 1` | **关键！** 让 n 长大，否则条件永远成立 → **死循环** |
| `print("Done!")` | 循环结束后打印 |

**灵魂点：** 循环体里必须有「让条件慢慢变假」的动作。`n = n + 1` 让 n 从 1→2→3→4→5→6，第 6 次条件不满足，跳出。

## 三、死循环与活循环（10 分钟）

故意写一个死循环看看：

```python
# DANGER: infinite loop
n = 1
while n <= 5:
    print(n)
    # forgot to add n = n + 1
```

点 Run 后会一直打 `1`。**Ctrl + C 强制停止**（Mac 也行）。死循环不可怕，怕的是你不知道它会死。

**避免死循环三件套：**

1. **起手值有**：循环变量必须有起手（`n = 1`）
2. **条件会变**：循环里必须有让条件慢慢靠近失败的步骤（`n += 1`）
3. **测试有上限**：写完先跑 5 秒，看会不会自己停

## 四、用 while 做点有用的（8 分钟）

### 4.1 数数到 N（用户决定）

```python
n = 1
end = int(input("Count to: "))
while n <= end:
    print(n)
    n += 1
```

输入 10 数到 10，输入 100 数到 100。**比 for 灵活**——用户自己决定几次。

### 4.2 累加到 100（用 while）

```python
total = 0
n = 1
while total < 100:
    total += n
    n += 1
print("Reached", total, "after", n - 1, "numbers")
```

计算 1+2+3+... 加到多少会超过 100。答案是 14（1+2+...+13=91，1+...+14=105）。

### 4.3 密码重试（无限次机会）

```python
password = "thawpaw"
guess = input("Password: ")
while guess != password:
    print("Wrong, try again")
    guess = input("Password: ")
print("Welcome!")
```

错就一直问，对了就退出。**应用场景**：登录重试、游戏开局、菜单系统。

## 五、⚠️ 新手三大坑（5 分钟）

1. **忘更新条件变量**：`while n <= 5: print(n)` 漏了 `n += 1` → 死循环，Ctrl + C 救命
2. **条件一开始就是假**：`while n < 0:` 但 n = 5 → 一次都不跑。`if` 不等于 `while`，后者跑了 0 次也是合法的
3. **`=` 与 `==` 老朋友**：`while guess = password:` 又一次 SyntaxError，**比较用 `==`**

老规矩：三个坑各故意踩一次，Ctrl + C 救命，再修好。
