## 一、坑①：`=` 与 `==` 混淆（3 分钟）

想写「如果年龄是 18」，手滑写成：

```text
age = 18
if age = 18:      # ❌ 错！
    print("18!")
```

**报错：** `SyntaxError: invalid syntax`（Python 直接拦下，一行都不跑）

**记牢一对：**

| 符号 | 名字 | 意思 |
|---|---|---|
| `=` | 一个等号 | **装进去**（赋值）：把右边装进左边 |
| `==` | 两个等号 | **比一比**（比较）：两边相等吗？ |

Python 把关把得好——这种错它替你拦下，感恩。

## 二、坑②：漏冒号（3 分钟）

```text
if score >= 60    # ❌ 行尾少了 :
    print("Passed!")
```

**报错：** `SyntaxError: expected ':'`——报错就在告诉你缺什么。if 行尾的冒号，一个不能少（else / elif / 以后的 for 全都一样）。

## 三、坑③：缩进忽长忽短（3 分钟）

```text
if score >= 60:
    print("Passed!")
   print("Nice!")    # ❌ 这行只缩了 3 格
```

**报错：** `IndentationError: unexpected indent`（或 unindent does not match）。

规矩：**统一 4 个空格，全文件一致**。Thonny 的 Tab 键就是按 4 格设计的，别手滑多敲一个空格。

## 踩坑三连的套路（今天作业的说明书）

1. 故意把错误代码敲进去
2. 运行，读**报错的最后一行**
3. 在注释里抄下这行报错
4. 修好，再跑一遍确认通过

**为什么值得踩：** 报错不是骂你，是程序在跟你说话。踩过一次、认得它的脸，下次它出现你就知道哪根线接错了。
