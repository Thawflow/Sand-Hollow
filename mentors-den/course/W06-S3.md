## 一、remove：按值删第一个（4 分钟）

```python
todos = ["homework", "gaming", "homework", "sleep"]
todos.remove("homework")
print(todos)     # ['gaming', 'homework', 'sleep']
```

`remove(x)` 删掉**第一个**等于 x 的元素——后面还有个 homework？它只删一个，剩下的不动。

**大坑：** 删一个不存在的值：

```text
todos.remove("unicorn")   # ❌ ValueError: list.remove(x): x not in list
```

**报错：** ValueError。防御姿势——**先 in 检查再删**（if "x" in list 才 remove）。

## 二、pop 与 clear：按位置删、一锅端（4 分钟）

```python
snacks = ["chip", "candy", "cookie", "juice"]
done = snacks.pop(1)
print(done, snacks)     # candy ['chip', 'cookie', 'juice']
snacks.pop()
print(snacks)           # ['chip', 'cookie']
```

- **pop(i)**：删第 i 个，而且**把它交还给你**（可以接住用）
- **pop()**：不写 i，删最后一个
- **clear()**：全部清空，变 `[]`

记忆：**remove 按值删第一个，pop 按位置删还退货，clear 一锅端**。

## 三、改：索引赋值（3 分钟）

```python
scores = [85, 92, 78]
scores[1] = 95
print(scores)    # [85, 95, 78]
```

**改 = 选中位置 = 赋值**，一行搞定。老规矩：门牌号不能越界，改 `[10]` 照样 IndexError。

**今日口诀：** remove 认值，pop 认位置还退货；改值最简单，门牌号加等号。
