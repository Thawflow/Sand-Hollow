## 一、概念：一个名字管一堆东西（5 分钟）

之前学的变量：一个名字管一个东西。

```python
name = "Alice"
age = 12
score = 95
```

但现实经常是「**一堆**」：

- 班级 30 个学生名单
- 购物车 10 件商品
- 玩家背包 100 个道具

**列表（list）= 一个变量管一堆数据**。这是 Scratch 里的「列表」积木，文字版。

## 二、列表的样子（8 分钟）

新建 `first_list.py`，亲手敲：

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(nums)
print(len(nums))
print(nums[0])
print(nums[3])
```

运行看：

```
[3, 1, 4, 1, 5, 9, 2, 6]
8
3
1
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `[3, 1, 4, ...]` | **方括号**包住一堆东西，**逗号**隔开 |
| `nums` | 列表的名字（一个变量管 8 个数） |
| `len(nums)` | 列表长度（8 个元素） |
| `nums[0]` | 第 1 个元素（Python 从 0 开始数！） |
| `nums[3]` | 第 4 个元素（0,1,2,**3** = 4） |

**关键观察：** `nums[0]` 是 3（第一个），不是 1。Python 从 0 开始数。这是新手最容易懵的地方。

### Shell 试玩

```python
>>> fruits = ["apple", "banana", "cherry"]
>>> fruits[0]
>>> fruits[-1]
>>> fruits[1]
```

`fruits[-1]` 是最后一个元素！负数 = 从尾巴数。

## 三、列表能装各种东西（8 分钟）

列表里**可以混搭不同类型**：

```python
mix = [42, "hello", 3.14, True, [1, 2]]
print(mix[1])
print(mix[4][0])
```

- `mix[1]` 是 `"hello"`（字符串）
- `mix[4]` 是 `[1, 2]`（嵌套列表）
- `mix[4][0]` 是 `1`（**两层方括号**，先取第 5 个，再取它的第 1 个）

**实战中混搭少用**——容易乱。新手期建议一个列表装同类型。

## 四、for 循环遍历列表（7 分钟）

W04 学的 for 循环，最常见用法就是「把列表里每个元素过一遍」：

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print("I like", fruit)
```

运行得：

```
I like apple
I like banana
I like cherry
```

`fruit` 是临时变量，每次循环拿一个水果。**起有意义的名字**比 `i` 更清楚。

### 关键点

- `for fruit in fruits:`：fruit 在 fruits 里逐个取
- 跟 `for i in range(3):` 不一样——前者**直接拿元素**，后者**拿索引 0/1/2**

## 五、用列表做点有用的（5 分钟）

### 5.1 班级名单

```python
classmates = ["Alice", "Bob", "Charlie", "Diana"]
print("Class size:", len(classmates))
for name in classmates:
    print(f"- {name}")
```

### 5.2 一周天气

```python
temps = [22, 25, 19, 30, 28, 24, 21]
total = 0
for t in temps:
    total += t
print(f"Week average: {total / len(temps):.1f}°C")
```

`{total / len(temps):.1f}` 保留 1 位小数（W02-L03 学的）。

## 六、⚠️ 新手三大坑（5 分钟）

1. **忘了从 0 开始**：`fruits[1]` 是第二个，不是第一个。**第一 = [0]**，记住
2. **索引越界**：`fruits[10]` 但列表只有 3 个 → `IndexError: list index out of range`
3. **混搭列表的 for 写法**：写了 `for i in range(len(fruits)):` 然后又写 `print(fruits[i])`——能用但繁琐，**直接 `for f in fruits:` 更 Pythonic**

老规矩：踩坑 1 + 2 时故意越界看报错。

## 八、练习答案（先做再看！）

**1.**
```python
fruits = ["apple", "banana", "cherry", "durian", "elderberry"]
print("Length:", len(fruits))

```

**2.**
```python
temps = [22, 25, 19, 30, 28, 24, 21]
total = 0
for t in temps:
    total += t
print(f"Week average: {total / len(temps):.1f}°C")
```

**3.**
```python
classmates = ["Alice", "Bob", "Charlie", "Diana", "Eve"]

    print("Hi,", name)
```

**4.**
```python
plans = ["family dinner", "drawing", "sports", "coding", "reading"]
for i, plan in enumerate(plans):
    print(f"Day {i+1}: {plan}")
```

`enumerate()` 是「打包索引 + 元素」，i 是 0/1/2/3/4，加 1 变 1-5。

**5.**
```python
nums = [12, 45, 7, 23, 56]
print(nums[0] + nums[2])  # 12 + 7 = 19
```

**6.**
```python
friends = []
for i in range(5):
    name = input(f"Friend {i+1} name: ")
    friends.append(name)
print("\nYour 5 friends:")
for name in friends:
    print("-", name)
```

`append()` 是「加到尾巴」——W06-L02 详细讲。
