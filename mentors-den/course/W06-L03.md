## 一、概念：W04-L02 学的累加器，套上列表（3 分钟）

W04 学过三个累加器：

- 求和：`total += x`
- 计数：`count += 1`
- 找最大：`if x > biggest: biggest = x`

今天把它们套上**列表**——这就是日常 80% 的「数据处理」代码。

## 二、求和 + 平均（5 分钟）

```python
scores = [85, 92, 78, 95, 88]
total = 0
for s in scores:
    total += s
print(f"Total: {total}, Average: {total / len(scores):.1f}")
```

`len(scores)` 取列表长度（W06-L01 学的）。

## 三、找最大 + 找最小（10 分钟）

```python
nums = [12, 45, 7, 23, 56, 89, 34]
biggest = nums[0]
smallest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
    if n < smallest:
        smallest = n
print(f"Biggest: {biggest}, Smallest: {smallest}")
```

### Python 偷懒写法（built-in）

上面都是「教学版」——自己写循环累加器。**实战中直接用 built-in：**

```python
nums = [12, 45, 7, 23, 56, 89, 34]
print(max(nums))   # 89
print(min(nums))   # 7
print(sum(nums))   # 266
```

- `max(列表)`：最大
- `min(列表)`：最小
- `sum(列表)`：求和（注意：只对数字列表）

**`sum/max/min` 是 Python 自带**，不用 import。W04-L02 教学版是打基础，实战用 built-in。

## 四、过滤 + 计数（10 分钟）

需求：班级 30 人，统计成绩 >= 90 的有几人。

```python
scores = [85, 92, 78, 95, 88, 90, 76, 91, 84, 89]
excellent = 0
for s in scores:
    if s >= 90:
        excellent += 1
print(f"Excellent (>=90): {excellent}")
```

**这就是「filter + count」模式**：

1. 循环
2. if 条件
3. 满足就 count +1

## 五、过滤后存新列表（10 分钟）

需求：把 >= 90 的成绩单独存进一个列表。

```python
scores = [85, 92, 78, 95, 88, 90, 76, 91, 84, 89]
excellent = []
for s in scores:
    if s >= 90:
        excellent.append(s)
print(f"Excellent scores: {excellent}")
```

运行得：

```
Excellent scores: [92, 95, 90, 91]
```

### Python 偷懒写法（list comprehension）

```python
excellent = [s for s in scores if s >= 90]
```

一行搞定。**`[表达式 for 变量 in 列表 if 条件]`** 是 list comprehension（列表推导式）。新手期建议先写循环版，能跑通再升级偷懒版。

## 六、综合实战：班级成绩单（7 分钟）


## 七、⚠️ 新手三大坑（5 分钟）

1. **空列表 max/min**：空列表用 max → `ValueError: max() arg is an empty sequence`。新手期少见，但写函数时会碰到
2. **混类型 sum**：`sum(["1", "2", "3"])` → `TypeError: unsupported operand type(s)`。**sum 只对数字**
3. **index 越界 + sum 累加错位**：教学版累加器忘建箱子 → NameError，**累加器必须先建再循环**（W04-L02 教训）

老规矩：踩坑 2 时故意 sum 一个字符串列表看报错。
