## 一、函数不只干活，还要交货（3 分钟）

前几天的函数都是 print 完就走。更多时候函数要**返回一个值**给调用方用：

- `input(...)` → 返回用户输入
- `random.randint(1, 100)` → 返回随机数
- W07 的 `battle(...)` → 返回 True/False（你早就用过 return 了）

## 二、return 的样子（4 分钟）

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
print(add(10, 20))
```

关键认知：**`add(3, 5)` 本身就是一个值**（8）。可以接住存变量、可以直接丢给 print、还可以继续参与计算——`add(3, 5) * 2` 就是 16。

## 三、return vs print：新手分水岭（4 分钟）

| | print | return |
|---|---|---|
| 给谁 | 显示给人看 | 交给程序用 |
| 能赋值吗 | 不能（得到 None） | 能 |
| 能参与计算吗 | 不能 | 能 |

```python
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

double = add_return(3, 5) * 2
```

上面 double 能算出 16；换成 add_print，它「打印了 8」但交出来的东西是 None——None 乘 2 直接 TypeError。**原则：要接住就用 return，纯展示才用 print。**

## 四、多个 return：见好就收（3 分钟）

```python
def find_biggest(nums):
    if not nums:
        return None
    biggest = nums[0]
    for n in nums:
        if n > biggest:
            biggest = n
    return biggest

print(find_biggest([3, 7, 2, 9, 4]))
print(find_biggest([]))
```

- `if not nums: return None`——空列表提前撤退（None = Python 的「无」）
- **第一个碰到的 return 立刻执行**，后面的代码不再跑
- 一个函数可以写多个 return，各管一条出口——跟 W07-S5「出口清点」一个思路

**今日口诀：** return 交货，print 展示；碰谁谁走，货能再算。
