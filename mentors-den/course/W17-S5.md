## 二、递归解迷宫（5 分钟）

```python
def solve_maze(maze, x, y, end_x, end_y, path=None):
    '''Recursive DFS. Returns path or None.'''
    if path is None:
        path = []

    # boundary check
    rows, cols = len(maze), len(maze[0])
    if not (0 <= x < rows and 0 <= y < cols):
        return None
    # hit wall or visited
    if maze[x][y] == 1 or (x, y) in path:
        return None
    # reach exit
    if x == end_x and y == end_y:
        return path + [(x, y)]

    # mark visited
    path.append((x, y))

    # try 4 directions: up, right, down, left
    for dx, dy in [(-1, 0), (0, 1), (1, 0), (0, -1)]:
        result = solve_maze(maze, x + dx, y + dy, end_x, end_y, path)
        if result:
            return result

    # backtrack on dead end
    path.pop()
    return None
```

## 四、深入了解：DFS vs BFS（3 分钟）

| 算法 | 找路径 | 找最短 |
|---|---|---|
| **DFS** (递归) | ✓ | ✗ 找到一条就行 |
| **BFS** (队列) | ✓ | ✓ 最短路径 |
| **A*** (启发式) | ✓ | ✓ 最优路径 |

**AI 工程师原则**：
- 简单解 → DFS（递归）
- 最短解 → BFS
- 大规模 + 启发式 → A*

## 五、何时用：递归在 AI 搜索（3 分钟）

| AI 场景 | 用递归？ |
|---|---|
| 迷宫 / 游戏 | ✓ DFS |
| 决策树（minimax）| ✓ alpha-beta 剪枝 |
| 图搜索 | ✓ DFS / BFS |
| 知识图谱查询 | ✓ BFS |
| 神经网络 forward | ✗ 用循环 |
| 训练优化（梯度下降）| ✗ 用循环 |

**99% 搜索算法是递归**。

## 👀 C++ 认脸时刻

```cpp
#include <vector>
#include <utility>
bool solveMaze(std::vector<std::vector<int>>& maze, int x, int y) {
    int rows = maze.size(), cols = maze[0].size();
    if (x < 0 || x >= rows || y < 0 || y >= cols) return false;
    if (maze[x][y] == 1) return false;
    if (x == rows - 1 && y == cols - 1) return true;
    maze[x][y] = 1;   // mark visited
    return solveMaze(maze, x+1, y) || solveMaze(maze, x, y+1);
}
```

三个认脸：
- C++ 迷宫用 `vector<vector<int>>`
- 标记走过 = 改成 1（省空间）
- `||` 短路求值：左边 true 就不算右边
