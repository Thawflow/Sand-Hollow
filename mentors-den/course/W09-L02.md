## 二、上色（10 分钟）

新建 `colorful_turtle.py`，亲手敲：

```python
import turtle

t = turtle.Turtle()
t.pensize(3)
t.speed(0)

# Line color
t.pencolor("red")
t.forward(100)

# Move without drawing
t.penup()
t.goto(-50, 0)
t.pendown()

# Fill color
t.fillcolor("yellow")
t.begin_fill()
for i in range(4):
    t.forward(80)
    t.left(90)
t.end_fill()
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `t.pencolor("red")` | 线条颜色（字符串或 RGB） |
| `t.pensize(3)` | 线条粗细（像素） |
| `t.fillcolor("yellow")` | 填充色 |
| `t.begin_fill()` | 开始记录填充区域 |
| `t.end_fill()` | 结束填充（涂满） |

**关键观察：** `begin_fill` 和 `end_fill` 之间画的形状会被涂满。

## 三、颜色写法（5 分钟）

### 字符串颜色

`"red"` `"blue"` `"green"` `"yellow"` `"purple"` `"orange"` `"pink"` `"cyan"` ...

### RGB 颜色（精确）

```python
t.pencolor(1.0, 0.5, 0.0)  # orange-ish (R=1.0, G=0.5, B=0.0)
```

三个 0-1 的浮点数 = 红绿蓝强度。

### 十六进制（HTML 颜色码）

```python
t.pencolor("#FF5733")  # coral
```

`#` 开头 + 6 位十六进制数。

## 四、速度（3 分钟）

```python
t.speed(0)   # fastest, no animation
t.speed(1)   # slowest
t.speed(10)  # very fast
t.speed("fastest")  # same as 0
```

速度从 1（最慢）到 10（最快），0 是「瞬移」。**画几何图常用 0**——不用等动画。

## 五、综合：彩色五角星（8 分钟）

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.pensize(2)

colors = ["red", "orange", "yellow", "green", "blue", "purple"]
for i in range(5):
    t.pencolor(colors[i])
    t.fillcolor(colors[i])
    t.begin_fill()
    t.forward(150)
    t.left(144)
    t.end_fill()
```

每画一条边换颜色——彩虹五角星。

## 七、⚠️ 新手三大坑（5 分钟）

1. **begin/end 不配对**：`begin_fill()` 后忘 `end_fill()` → 没填充；`end_fill()` 多了一次 → `TurtleGraphicsError`
2. **颜色名打错**：`t.pencolor("reddd")` → `TurtleGraphicsError: bad color sequence`（拼写错误）
3. **goto 时还落着笔**：`t.goto(100, 100)` 没 penup → 画一条不需要的线

```cpp
const double PI = 3.14159;   // 常量：定了不许改
```
