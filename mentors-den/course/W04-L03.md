## 二、第一招：画 3 排 5 列的星星（8 分钟）

新建 `grid_stars.py`，亲手敲：

```python
for row in range(3):
    for col in range(5):
        print("*", end=" ")
    print()
```

运行得：

```
* * * * * 
* * * * * 
* * * * * 
```

### 逐字拆解「嵌套循环三件套」

| 部件 | 作用 |
|---|---|
| 外层 `for row in range(3)` | 管「行」：做 3 遍 |
| 内层 `for col in range(5)` | 管「列」：每次做 5 遍 |
| `print("*", end=" ")` | 打星星 + 空格，不换行 |
| `print()` | 内层走完一整行，外层接一次换行 |

**关键点：** 内层走完 5 次 → 换行 → 外层再走下一次。外层每走一次，内层走完一整轮。

### Shell 追踪执行顺序

外层 row=0 → 内层 col=0,1,2,3,4 → 换行 → 外层 row=1 → 内层又来一遍... 反复 3 次。

**执行总数 = 外层 × 内层 = 3 × 5 = 15 次 `print("*")`**。

## 二点五、 `end=" "` 是什么（3 分钟）

`print` 默认每句结尾换行（`end="\n"`）。`end=" "` 改成「以空格结尾」，这样星星就能横着排：

```python
print("Hello")        # default: end="\n"
print("World")        # default: end="\n"

print("Hello", end=" ")  # end=" ": space instead of newline
print("World")           # default: end="\n" → "Hello World\n"
```

记住：`end` 控制 print 句尾加什么，不写默认换行。

## 三、第二招：画直角楼梯（10 分钟）

新建 `staircase.py`，亲手敲：

```python
for row in range(1, 6):
    for col in range(row):
        print("*", end=" ")
    print()
```

运行得：

```
* 
* * 
* * * 
* * * * 
* * * * * 
```

### 关键观察

外层 row 从 1 走到 5；内层 `range(row)` 让每行的星星数等于行号：
- row=1 → col 走 1 次 → 1 个星
- row=2 → col 走 2 次 → 2 个星
- ...
- row=5 → col 走 5 次 → 5 个星

**这是嵌套循环最经典的形态：「外层管行号，内层管每行宽度」。**

## 四、第三招：画金字塔（10 分钟）

楼梯歪一边不好看，**金字塔左右对称**——前面加空格让每行居中。

新建 `pyramid.py`，亲手敲：

```python
height = 5
for row in range(1, height + 1):
    # Leading spaces to center
    for space in range(height - row):
        print(" ", end="")
    # Stars in this row
    for star in range(2 * row - 1):
        print("*", end="")
    print()
```

运行得：

```
    *
   ***
  *****
 *******
*********
```

### 拆解

- `height - row`：这一行前面要补多少空格（行号越大，空格越少）
- `2 * row - 1`：这一行要打多少个星（1, 3, 5, 7, 9）

**公式记忆：** 第 N 行的星数 = 2N - 1。这是数学规律（奇数序列），不是死记——W05 数列题还会回来。

## 五、⚠️ 新手三大坑（5 分钟）

1. **缩进三层乱了**：嵌套循环有 3 层缩进（外层、内层、内层里的 print），一格错全乱。规矩：统一 4 空格，Thonny 自动帮你缩。
2. **`end=""` 漏了空格**：忘记 `end=""` 或 `end=" "`，每行只出 1 个星就换行。看着像「为什么只有第一行有星？」——多半是这个。
3. **`print()` 漏在循环内**：内层走完要换行（`print()`），如果漏了，所有星星挤一行。

老规矩：三个坑各故意踩一次，读报错最后一行，再修好。
