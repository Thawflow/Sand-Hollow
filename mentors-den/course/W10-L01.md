## 一、概念：用「名字」找东西（5 分钟）

W06 学的列表：用**数字索引**（`[0]`、`[1]`、`[2]`）找东西。
W07 项目周玩家状态用过字典：**用名字**找东西。

```python
player = {"name": "Paw", "hp": 100, "attack": 10}
print(player["name"])   # "Paw"
print(player["hp"])     # 100
```

**字典 = 名字 → 东西 的映射表**。类似现实中的电话簿：「小明 → 13800138000」。

## 二、字典的样子（8 分钟）

新建 `first_dict.py`，亲手敲：

```python
cat = {
    "name": "Whiskers",
    "age": 3,
    "color": "tabby",
    "is_indoor": True,
}

print(cat)
print(cat["name"])
print(cat["age"])
print(cat["color"])
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `{...}` | 花括号包住字典（区别于列表的 `[...]`） |
| `"name": "Whiskers"` | **键: 值** 一对 |
| 键（key） | 名字（必须加引号的字符串） |
| 值（value） | 任何东西（字符串、数字、布尔、列表、字典） |

## 三、增删改查（10 分钟）

```python
cat = {"name": "Whiskers", "age": 3}

# Add
cat["color"] = "tabby"
print(cat)

# Read
print(cat["name"])

# Update
cat["age"] = 4
print(cat["age"])

# Delete
del cat["color"]
print(cat)

# Check existence
if "name" in cat:
    print("Has name")

# Loop
for key in cat:
    print(f"{key} -> {cat[key]}")
```

### 拆解

- **`cat["color"] = "tabby"`**：**改 = 选中键 = 赋值**（同列表）
- **`del cat["color"]`**：删除键值对
- **`if "name" in cat`**：检查键在不在（True/False）
- **`for key in cat`**：循环遍历所有键
- **`cat[key]`**：通过键拿值

## 四、字典 vs 列表（5 分钟）

| 场景 | 用列表 | 用字典 |
|---|---|---|
| 一组数 [3, 1, 4, 1, 5] | ✅ | 麻烦 |
| 玩家状态 {name, hp, atk} | 麻烦 | ✅ |
| 通讯录 {名字 → 电话} | 麻烦 | ✅ |
| 排行榜 {排名 → 分数} | ✅ | 也行 |
| 一周温度 [22, 25, 19, ...] | ✅ | 麻烦 |

**判断标准：** 位置重要吗？→ 列表。名字重要吗？→ 字典。

## 五、实战：通讯录（7 分钟）

```python
contacts = {
    "Alice": "13800138001",
    "Bob": "13800138002",
    "Charlie": "13800138003",
}

name = input("Name to look up: ")
if name in contacts:
    print(f"{name}'s number: {contacts[name]}")
else:
    print(f"{name} not in contacts")
```

## 六、⚠️ 新手三大坑（5 分钟）

1. **用列表的方括号 + 数字**：`cat[0]` 但字典没有 0 键 → KeyError。**用 cat["name"]**
2. **键拼错**：`cat["naem"]` → KeyError。**先 print(cat.keys()) 看有哪些键**
3. **改 vs 重新赋值混淆**：`cat = {}` 是新建空字典，**不是清空原字典**。要清空用 `cat.clear()`
