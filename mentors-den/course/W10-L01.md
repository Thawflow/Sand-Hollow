## 一、概念：让程序「画」出来（5 分钟）

W01-W08 的程序都是「文字输出」。**turtle** 让程序「画」出来——一个虚拟小海龟，按你的指令在屏幕上爬行，画出线条。

```python
import turtle
t = turtle.Turtle()
t.forward(100)  # forward 100 pixels
t.left(90)      # turn 90 degrees left
```

**应用场景**：画几何图形（正方形、三角形、五角星）、画雪花、画螺旋。**视觉化让代码有「画」的感觉**，比 print 直观 10 倍。

## 二、起笔 + 第一个形状（10 分钟）

新建 `first_turtle.py`，亲手敲：

```python
import turtle

t = turtle.Turtle()

# Draw a square
for i in range(4):
    t.forward(100)
    t.left(90)
```

运行：弹出一个窗口，海龟画一个 100×100 的正方形。

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `import turtle` | 引入 turtle 模块（Python 自带） |
| `t = turtle.Turtle()` | 创建一只海龟 |
| `t.forward(100)` | 前进 100 像素 |
| `t.left(90)` | **左转 90 度**（不是弧度，是角度）|
| `for i in range(4):` | 循环 4 次 = 4 条边 = 正方形 |

**海龟默认朝右**（东方）。`left(90)` 让它转向上方（北方）。

## 三、关键命令表（5 分钟）

| 命令 | 作用 | 例子 |
|---|---|---|
| `forward(n)` | 前进 n 像素 | `t.forward(100)` |
| `backward(n)` | 后退 n 像素 | `t.backward(50)` |
| `left(deg)` | 左转 deg 度 | `t.left(90)` |
| `right(deg)` | 右转 deg 度 | `t.right(45)` |
| `penup()` | 抬笔（移动不画） | `t.penup()` |
| `pendown()` | 落笔（开始画） | `t.pendown()` |
| `goto(x, y)` | 直接跳到坐标 (x, y) | `t.goto(0, 100)` |
| `speed(n)` | 速度 1-10，0 最快 | `t.speed(0)` |

## 四、画几个常见形状（10 分钟）

### 4.1 等边三角形

```python
for i in range(3):
    t.forward(100)
    t.left(120)  # 360 / 3 = 120
```

### 4.2 五角星

```python
for i in range(5):
    t.forward(100)
    t.left(144)  # 360 / 5 = 72, but draw line every 144 (skip ahead)
```

**关键观察：** 五角星每次转 144° = 180° - 36°（外角 = 180° - 内角）。

### 4.3 通用正多边形

```python
def polygon(sides, length):
    angle = 360 / sides
    for i in range(sides):
        t.forward(length)
        t.left(angle)

polygon(6, 50)  # hexagon
polygon(8, 50)  # octagon
```

**重点是循环 + 角度公式**——W04-L01 + W08-L01 综合应用。

## 五、保存窗口（5 分钟）
