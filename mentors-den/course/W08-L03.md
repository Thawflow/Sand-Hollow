## 一、概念：函数不只做事，还能「交货」（5 分钟）

W08-L01/L02 的函数都是 `print` 出东西。但**更多时候函数要返回一个值**，给调用方用：

- `calculate(a, b)` → 返回计算结果
- `input("...")` → 返回用户输入
- `random.randint(1, 100)` → 返回随机数

`return` 就是函数「吐结果」的关键字。

## 二、return 的样子（8 分钟）

新建 `first_return.py`，亲手敲：

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8
print(add(10, 20))  # 30
```

### 逐字拆解

| 部件 | 作用 |
|---|---|
| `return a + b` | 把 a+b 的值「吐」给调用方 |
| `result = add(3, 5)` | 函数调用 = 一个值（可以接住） |
| `print(add(10, 20))` | 直接用返回值，不需要中间变量 |

**关键观察：** `add(3, 5)` 本身**就是一个值**（这里是 8），可以赋值给变量，可以传给 print，可以传给别的函数。

## 三、多个 return（5 分钟）

```python
def find_biggest(nums):
    if not nums:
        return None  # empty list returns None
    biggest = nums[0]
    for n in nums:
        if n > biggest:
            biggest = n
    return biggest

print(find_biggest([3, 7, 2, 9, 4]))  # 9
print(find_biggest([]))  # None
```

### 拆解

- **`return None`**：空列表时返回 None（Python 的「无」）
- **多个 return**：第一个匹配的就返回，后面不执行
- **`return biggest`**：正常返回

## 四、return vs print 的区别（8 分钟）

| | print | return |
|---|---|---|
| 用途 | 显示给人看 | 给程序接住用 |
| 能否赋值 | 不能 | 能 |
| 能否参与计算 | 不能 | 能 |

```python
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

# print version
add_print(3, 5)  # shows 8 but result is None
# result = add_print(3, 5)  # result = None (print returns nothing)

# return version
result = add_return(3, 5)  # result = 8
double = add_return(3, 5) * 2  # double = 16
```

**实战原则：** 需要接住结果 → return；只是显示给人看 → print。

## 五、实战：use_item 升级（10 分钟）

W07-L03 的 use_item 可以加 return 告诉调用方「用没用成功」：

```python
def use_item(player, item_name):
    if item_name not in player["inventory"]:
        print(f"You don't have {item_name}")
        return False  # item not in inventory

    item = items_db[item_name]
    if item["effect"] == "heal":
        player["hp"] = min(player["max_hp"], player["hp"] + item["value"])
        print(f"Used {item['name']}!")
    elif item["effect"] == "attack":
        player["attack"] += item["value"]
        print(f"Used {item['name']}!")

    player["inventory"].remove(item_name)
    return True  # used successfully
```

调用方：

```python
if use_item(player, "herb"):
    print("Healing done!")
else:
    print("No herb left")
```

**return True/False 让调用方知道结果**，便于做后续判断。

## 六、提前退出：return 立刻结束函数（5 分钟）

```python
def divide(a, b):
    if b == 0:
        print("Cannot divide by zero")
        return None
    return a / b

result = divide(10, 0)
print(result)  # None
result = divide(10, 2)
print(result)  # 5.0
```

`return None` 立即结束函数，**后面的代码不执行**。这叫「提前退出」——遇到错误立刻返回，不继续往下走。

## 七、⚠️ 新手三大坑（5 分钟）

1. **return vs print 混用**：以为 `return` 会自动 print 出来。**return 只是给程序，不显示**
2. **忘 return**：函数没有 return → 默认返回 None，调用方拿到 None 不知道发生了什么
3. **return 后还有代码**：return 立刻结束函数，return 之后的代码不执行（不是 bug，是设计）
