## 一、营地的储物难题（3 分钟）

猫武士大战告捷，猎物堆成山：100 只老鼠、40 只兔子、12 条鱼……**副族长要怎么存这份家底？**

 data 结构（数据结构）这门功夫，研究的就是"**东西怎么摆，才好找好放**"。今天学最经典的两种摆法——你已经在用它俩了（Python 列表≈其中一种），只是今天才看清它们的脸。

## 二、数组：连排储物柜（10 分钟）

### 长什么样

100 格储物柜**紧挨着排成一条直线**，从 0 号编到 99 号。每只猎物住一格。

```
编号:  0      1      2      3      4
     [mouse][mouse][rabbit][fish ][vole ]
```

### 两个绝活

**绝活①：一步直达第 k 格。** 副族长喊"查 3 号柜"——直接走到 3 号，**一步都不多走**。W06 你早就写过：

```python
prey = ["mouse", "mouse", "rabbit", "fish", "vole"]
print(prey[3])        # 一步直达：fish
```

为什么能直达？柜子紧挨着 + 编号从 0 开始 → 内存地址能**算出来**（首地址 + k × 每格大小）。这是数学，不是运气。

**绝活②的代价：插队要全员挪窝。** 新猎物想插进 2 号位（当"贵宾"），2 号及后面的住户**全部往后挪一格**：

```python
prey = ["mouse", "mouse", "rabbit", "fish", "vole"]
prey.insert(2, "bird")     # 鸟要住 2 号位
print(prey)   # ['mouse', 'mouse', 'bird', 'rabbit', 'fish', 'vole'] —— 后面 3 位全被挤后移
```

一行代码看着轻松，**幕后挪了 3 格**。柜子越多，插队越贵——电影院中间 insert 一个座位，半排人跟着起立。

## 三、链表：寻宝纸条（10 分钟）

### 长什么样

不给柜子编号了。每个猎物住进**散落各处的小屋**，屋里除了猎物，还有**一张纸条，写着下一户的地址**：

```
(mouse, 去3号屋) → (rabbit, 去7号屋) → (fish, 去1号屋) → (vole, 到头了)
```

### 两个绝活（跟数组正好掉了个）

**绝活①：插队不挪窝。** 鸟想插在 rabbit 前面？只需：mouse 屋的纸条改成"去鸟屋"，鸟屋放纸条"去 rabbit 屋"——**改两张纸条，别人家碰都不用碰**。

**绝活②的代价：找第 k 个必须顺藤摸瓜。** 想知道第 3 户是谁？没有编号不能直达，只能从第一家开始，读纸条、走一户、再读纸条……走几户才能到第几户。

### 用两个列表亲手模拟（核心练习）

真纸条我们没有，用**两个列表**扮演链表：一个存值，一个存"下一家的门牌号"：

```python
vals  = ["mouse", "rabbit", "fish", "vole"]     # 各家住的猎物
nexts = [1, 2, 3, -1]    # 各家的纸条：去几号屋？-1 表示"到头了"

# 走一趟完整的链（顺藤摸瓜）
i = 0
while i != -1:
    print(vals[i])
    i = nexts[i]

# 鸟插进 mouse 和 rabbit 之间：只动两张纸条
vals.append("bird")        # 鸟住进 4 号屋（新家，谁也不挤）
nexts.append(2)            # 鸟的纸条：去 2 号屋（rabbit）
nexts[0] = 4               # mouse 的纸条改指向：去 4 号屋（鸟）

i = 0
while i != -1:
    print(vals[i])
    i = nexts[i]
```

**先猜第二趟输出**，再跑。改两张纸条 = 插队完成，全场只动了 `nexts[0]` 和新增一家——这就是链表的绝活。

## 四、对比表：什么时候用谁（5 分钟）

| 操作 | 数组（格子间） | 链表（寻宝纸条） |
|---|---|---|
| 查第 k 个 | ⚡ 一步直达 | 🐢 走 k 步 |
| 末尾加一个 | ⚡ 便宜 | ⚡ 便宜（找到尾巴后） |
| 中间插一个 | 🐢 后面全挪 | ⚡ 改两张纸条 |
| 连续扫一遍 | ⚡ 顺着走 | 🐢 一户一户跳 |

一句话总结：**数组利索在"跳"，链地利索在"插"**。没有全胜的摆法，只有合不合身手——数据结构的第一课就是"取舍"（trade-off）。

顺便揭个底：Python 的 `list` 是数组家族的（底层是连续内存的动态数组），所以 `prey[3]` 才那么快；它 insert 慢也正因为此。W10 字典则是另一种更神奇的摆法（哈希——寒假正篇再说）。

## 六、练习答案（先做再看！）

**1.** `['mouse', 'mouse', 'bird', 'rabbit', 'fish', 'vole']`。

**2.** 第一趟：mouse rabbit fish vole；第二趟：mouse bird rabbit fish vole。

**3.** 打印 mouse fish vole——**rabbit 被跳过了**！mouse 的纸条一改，rabbit 还住在屋里，但再没有纸条指向它，从队伍里"失踪"了。链表删除 = 改纸条，不用搬家。

**4.** `vals.append("hawk")`（住 4 号屋）、`nexts.append(3)`（hawk 的纸条去 3 号屋 = vole）、`nexts[2] = 4`（fish 的纸条改指 hawk）。输出变为 mouse rabbit fish hawk vole。

**5.** 死循环——纸条绕成一圈，`while i != -1` 永远等不到 -1，一直打印 mouse rabbit fish vole……循环链表没有"到头"，**基线消失**，和递归没有基线是一回事（连 Ctrl+C 都要用上）。

## 七、🤖 AI 常识胶囊 · 第 8 颗：AI 的"上学"和"考试"（3 分钟）

> 今天的对比表藏着一个大道理：**同一样东西，干不同的事，成本完全不同**。AI 也分两个完全不同的工作状态：

- **训练（上学）**：读海量数据、调整内部参数——几万张显卡跑几个星期甚至几个月，电费以千万计。**一生主要上这么几次学。**
- **推理（考试/干活）**：你发一句"讲讲汉诺塔"，它猜词作答——几秒搞定。**天天都在考。**

所以：训练一次贵得吓人，推理一次便宜得多。你问它问题，**不会让它当场学新东西**——它用的是"上学时"装进脑子里的本事（参数不变），这也是它不知道今天新闻的原因（除非联网查）。

**⚔️ 判一判（先自己答，再看答案）**

1. 你每问大模型一个问题，它就当场多学一点新知识。
2. 训练一次大模型花的算力，比回答一个问题多得多。

**答案**：1 ✗（回答发生在推理期，参数不变——想让它"学"要重新训练或专门微调）；2 ✓（上学和考试的成本差着几个数量级，对齐今天"数组查得快/插得贵"的取舍思维）。

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

> ⚠️ 重点课：**AI 营笔试考过"单向链表"**——这张脸必须认熟。

```cpp
#include <iostream>
struct Node { int val; Node* next; };    // 认脸①：一节车厢 = 值 + 下一节的位置（纸条）
int main() {
    Node a, b;                           // 认脸②：先造两节车厢
    a.val = 3; b.val = 7;                // 认脸③：车厢里装货
    a.next = &b; b.next = 0;             // 认脸④：& 是"取地址"（写纸条）；0 = 到头了
    std::cout << a.val << " " << a.next->val;   // 认脸⑤：-> 顺着纸条取货
    return 0;
}
```

认脸口诀：**`struct Node` 造车厢，`next` 是纸条，`&` 写地址，`->` 顺藤摸瓜。** 考卷上看到 `p = p->next`，就是"跟着纸条走一户"。
