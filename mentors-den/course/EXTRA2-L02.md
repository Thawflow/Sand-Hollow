## 二、汉诺塔：三根柱子和三片金盘（10 分钟）

道具：三根柱子 A（出发地）、B（中转站）、C（目的地），3 片大小不同的"金盘"（用 3 枚大小不同的硬币 + 3 张写着 A/B/C 的纸就能玩）。

规矩两条：

1. 一次只能搬**一片**
2. 任何时候**大盘不能压小盘**

**先手玩**：把 3 片从 A 全部搬到 C，最少几步？拿硬币真玩，边玩边记步骤（不许先看答案！）。

玩出来的最少步数是 **7 步**。3 片 = 7 步，这个 7 待会儿有大用。

### 递归怎么看汉诺塔

别盯着 7 步看，用"族长思维"分解：

> 把 3 片从 A 搬到 C = ① 把**上面 2 片**从 A 挪到 B（中转）→ ② 把**最大片**从 A 搬到 C → ③ 把那 2 片从 B 挪到 C。

第 ① 步"搬 2 片"是什么？——**同一个问题的小一号版本**！递归的味道出来了：搬 n 片 = 搬 (n-1) 片 + 搬 1 片 + 搬 (n-1) 片。基线：只剩 1 片，直接搬。

## 三、代码：三行核心，打印全部步骤（15 分钟）

```python
def hanoi(n, start, via, goal):
    """把 n 片金盘从 start 柱搬到 goal 柱，via 柱当中转"""
    if n == 1:
        print(start, "->", goal)      # 基线：一片，直接搬
        return
    hanoi(n - 1, start, goal, via)    # ① 上面 n-1 片挪去中转
    print(start, "->", goal)          # ② 最大片直达目的地
    hanoi(n - 1, via, start, goal)    # ③ n-1 片从中转搬过来

hanoi(3, "A", "B", "C")
```

先猜会打印几行，再跑——数一数，正好 **7 行**，和你手玩的 7 步一模一样。

**读程序挑战**（笔试题型，纯脑内）：`hanoi(2, "A", "B", "C")` 会打印哪几行？先猜，再跑验证。（答案：第六节）

### 步数的秘密

| 片数 | 最少步数 | 规律 |
|---|---|---|
| 1 | 1 | 2¹ - 1 |
| 2 | 3 | 2² - 1 |
| 3 | 7 | 2³ - 1 |
| 4 | 15 | 2⁴ - 1 |
| n | **2ⁿ - 1** | 每加一片，步数翻倍再 +1 |

64 片 = 2⁶⁴ - 1 ≈ 1846 亿亿步——僧侣一秒搬一片也要搬 5845 亿年。这就是加餐①"每次砍半"的孪生兄弟：**每加一层，翻一倍**。二分是往下砍，递归塔是往上垒，长得飞快。

## 四、turtle 分形树：递归的画（10 分钟）

W09 你用 turtle 画过正方形和雪花。现在画一棵**真正的树**：树干走到头，分叉出两根树枝；**每根树枝自己又是一棵小树**——小树再分叉……

```python
import turtle

def tree(t, length, depth):
    if depth == 0:              # 基线：枝头太细，不画了
        return
    t.forward(length)           # 画这一段树干
    t.left(30)
    tree(t, length * 0.7, depth - 1)   # 左边的子树（小一号）
    t.right(60)
    tree(t, length * 0.7, depth - 1)   # 右边的子树（小一号）
    t.left(30)
    t.backward(length)          # 退回分叉点，别忘了收笔

t = turtle.Turtle()
t.left(90)                      # 树往上长
t.speed(0)
tree(t, 100, 4)
turtle.done()
```

看代码找脸熟：`tree` 的身体里出现了**两次 tree**——每个分叉点长出两棵子树。`depth` 每层减 1，就是"每一步更靠近基线"。

**动手实验**：把 `depth` 从 1 改到 6，一棵比一棵茂密。depth = 7、8 时画面会明显变慢——树枝数量 2ᵈₑₚₜʰ 根，翻倍式增长，画不完的树（周末还要跟它算总账）。

## 六、练习答案（先做再看！）

**1.** 7 行：`A->C`、`A->B`、`C->B`、`A->C`、`B->A`、`B->C`、`A->C`。

**2.** 3 行：`A->B`、`A->C`、`B->C`。（① 上面 1 片去 B；② 最大片去 C；③ 那片从 B 到 C。）

**3.** 2⁵ - 1 = **31 步**。

**4.** 开放题。角度越小树越"瘦高"，越大越"张开"——但不管怎么改，**分叉结构不变**，因为递归骨架没动。

**5.** 提示版答案：

```python
def hanoi(n, start, via, goal, counter):
    if n == 1:
        print(start, "->", goal)
        counter[0] = counter[0] + 1
        return
    hanoi(n - 1, start, goal, via, counter)
    print(start, "->", goal)
    counter[0] = counter[0] + 1
    hanoi(n - 1, via, start, goal, counter)

steps = [0]                      # 用列表当"可变的记分牌"
hanoi(4, "A", "B", "C", steps)
print("共", steps[0], "步")       # 共 15 步
```

## 八、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

今天的"数树枝"，C++ 用斐波那契数（1 1 2 3 5 8……后一个 = 前两个之和）当例子——它和分形树一样，函数身体里**调用自己两次**：

```cpp
#include <iostream>
int fib(int n) {                       // 认脸①：还 int 的函数
    if (n < 2) return n;               // 认脸②：基线先到（fib(0)=0, fib(1)=1）
    return fib(n - 1) + fib(n - 2);    // 认脸③：自己调自己，还调了两次！
}
int main() {
    std::cout << fib(10);              // 55
    return 0;
}
```

认脸要点：`fib` 在自己身体里出现**两次**——这正对应分形树每个分叉长两棵子树。左脸右脸都认识，笔试见它不慌。
