## 三、项目 B：综合读程序挑战（10 分钟）

一段"三课连招"的代码（排序 + 求和 + 贪心），**纯脑内**预测输出，填完再跑：

```python
nums = [4, 1, 3, 2]

def sort_up(a):                      # 甲函数
    for i in range(len(a) - 1):
        best = i
        for j in range(i + 1, len(a)):
            if a[j] < a[best]:
                best = j
        if best != i:
            temp = a[i]; a[i] = a[best]; a[best] = temp
    return a

def pick(a, budget):                 # 乙函数
    total = 0
    for x in a:
        if x <= budget - total:
            total = total + x
    return total

print(sort_up(nums))
print(pick(sort_up(nums), 5))
print(pick(sort_up([6, 5, 1]), 6))
```

三问：

1. 第一个 print 输出？
2. 第二个 print 输出？（甲给乙铺了什么路？）
3. 第三个 print 输出？最优其实是多少？

## 五、🤖 AI 常识胶囊 · 第 13 颗：Agent——会自己干活的 AI + 13 颗盘点（5 分钟）

> 收官胶囊讲一个最新潮的词：**Agent（智能体）** = 不只会聊天，还会**自己拆任务、用工具、分步干活**的 AI。你说"帮我查天气并约提醒"，它自己分几步：查天气 → 看日历 → 建提醒。大模型是"嘴"，Agent 是"嘴 + 手"。

和贪心对照着记：Agent 每一步也常是"选眼下的下一步"——但好的 Agent 会**回头检查**（这一步对不对？要不要重来），**不回头的是差 Agent，老想回头的是磨蹭**。算法即人生。

**⚔️ 判一判（先自己答，再看答案）**

1. Agent 指能自己拆解任务、调用工具、分步完成目标的 AI。
2. 只能一问一答聊天的 AI 也叫 Agent。

**答案**：1 ✓（嘴 + 手，会干活）；2 ✗（那是聊天机器人，"手"是 Agent 的门槛）。

## 六、👀 C++ 认脸时刻（1 分钟 · 只看不敲）

收官认一张"老面孔新组合"：while 版找零（只数 25 分硬币有几枚）：

```cpp
#include <iostream>
int main() {
    int money = 68, c25 = 0;
    while (money >= 25) {            // 认脸①：只要还塞得下就继续
        money = money - 25;
        c25 = c25 + 1;
    }
    std::cout << "25分 " << c25 << " 枚，剩 " << money << " 分";
    return 0;
}
```
