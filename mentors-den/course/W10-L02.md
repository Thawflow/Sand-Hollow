## 一、概念：字典能装任何东西（3 分钟）

字典的值可以是**任何东西**——字符串、数字、布尔、**列表**、**另一个字典**。

这种「字典里套字典/列表」叫**嵌套**，是数据建模的核心。

## 二、字典套列表（10 分钟）

新建 `nested_list.py`，亲手敲：

```python
player = {
    "name": "Paw",
    "hp": 100,
    "inventory": ["sword", "shield", "potion"],
}

print(player["inventory"])
print(player["inventory"][0])
print(player["inventory"][1])

# Add to inventory
player["inventory"].append("key")
print(player["inventory"])

# Loop
for item in player["inventory"]:
    print(f"- {item}")
```

### 拆解

- **`player["inventory"]`**：先取 inventory 键（得到列表）
- **`player["inventory"][0]`**：再取列表的第 1 个元素
- **`player["inventory"].append(...)`**：调用列表的 append 方法
- **`for item in player["inventory"]:`**：遍历列表

**关键点：** 「键拿值」+「列表索引」= 两步取具体元素。

## 三、字典套字典（10 分钟）

新建 `nested_dict.py`：

```python
cat = {
    "name": "Whiskers",
    "stats": {
        "hp": 50,
        "attack": 12,
        "defense": 5,
    },
    "skills": {
        "scratch": {"damage": 8, "uses": 5},
        "purr": {"heal": 10, "uses": 3},
    },
}

print(cat["name"])
print(cat["stats"]["hp"])
print(cat["skills"]["scratch"]["damage"])

# Update nested
cat["stats"]["hp"] += 10

# Add new skill
cat["skills"]["bite"] = {"damage": 15, "uses": 2}
print(cat["skills"])
```

### 拆解

- **`cat["stats"]["hp"]`**：cat → stats 键 → hp 键 → 值
- **`cat["stats"]["hp"] += 10`**：嵌套值累加
- **`cat["skills"]["bite"] = ...`**：嵌套添加新键

**深度嵌套时要一步步「下钻」**，每一步用方括号 + 字符串键。

## 四、实战：班级花名册升级版（12 分钟）

```python
classes = {
    "Math": [
        {"name": "Alice", "score": 92},
        {"name": "Bob", "score": 78},
    ],
    "English": [
        {"name": "Alice", "score": 88},
        {"name": "Bob", "score": 85},
    ],
}

# Print all scores for Alice
print("Alice's scores:")
for subject in classes:
    for student in classes[subject]:
        if student["name"] == "Alice":
            print(f"  {subject}: {student['score']}")
```

**结构：**
- `classes` = 字典（科目 → 列表）
- 每个列表 = 一组学生（每个学生是字典）
- 学生字典 = name + score

三层嵌套，但每层都是熟悉的结构。

## 五、⚠️ 新手三大坑（5 分钟）

1. **KeyError 套娃**：`cat["stat"]["hp"]` 但键是 `stats`（带 s）→ KeyError。**一步一步 print 调试**
2. **列表 vs 字典混淆**：`player[0]` 但 player 是字典 → KeyError 0
3. **修改副本而非原值**：`inv = player["inventory"]; inv.append("x")` 实际改了原列表（**列表是引用**）。新手期少见，混个脸熟
