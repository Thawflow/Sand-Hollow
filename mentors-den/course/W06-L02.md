## 一、概念：列表的日常四件事（3 分钟）

列表创建之后，99% 的时间都在做四件事：

- **增**：往里加（append / insert）
- **删**：拿出来（remove / pop / clear）
- **改**：换掉（直接用索引赋值）
- **查**：找一找（in / index / count）

记住口诀：**「增删改查」**——这是所有数据结构的通用词。

## 二、增：append 和 insert（10 分钟）

新建 `list_grow.py`，亲手敲：

```python
pets = ["cat", "dog"]
print("Start:", pets)

pets.append("rabbit")
print("After append:", pets)

pets.append("hamster")
print("After append 2:", pets)

pets.insert(1, "fish")
print("After insert at 1:", pets)
```

运行看每一步的变化：

```
Start: ['cat', 'dog']
After append: ['cat', 'dog', 'rabbit']
After append 2: ['cat', 'dog', 'rabbit', 'hamster']
After insert at 1: ['cat', 'fish', 'dog', 'rabbit', 'hamster']
```

### 拆解

- **`append(x)`**：把 x 加到**末尾**
- **`insert(i, x)`**：把 x 插到**第 i 个位置**，原元素往后挤

记忆：**append 是排队插尾巴，insert 是插队**。

## 三、删：remove / pop / clear（10 分钟）

新建 `list_shrink.py`：

```python
todos = ["homework", "gaming", "homework", "sleep", "homework"]
print("Start:", todos)

todos.remove("homework")
print("After remove first 'homework':", todos)

done = todos.pop(1)
print(f"Popped '{done}', list:", todos)

todos.pop()
print("After pop():", todos)

todos.clear()
print("After clear:", todos)
```

运行得：

```
Start: ['homework', 'gaming', 'homework', 'sleep', 'homework']
After remove first 'homework': ['gaming', 'homework', 'sleep', 'homework']
Popped 'gaming', list: ['homework', 'sleep', 'homework']
After pop(): ['homework', 'sleep']
After clear: []
```

### 拆解

- **`remove(x)`**：删**第一个**等于 x 的元素（没有就报错）
- **`pop(i)`**：删**第 i 个**元素，并且**返回它**（可以接住）
- **`pop()`**：不写 i 删最后一个
- **`clear()`**：全部清空

记忆：**remove 按值删（删第一个匹配的），pop 按位置删（顺便告诉你删了啥），clear 一锅端**。

## 五、查：in / index / count（7 分钟）

```python
fruits = ["apple", "banana", "cherry", "banana"]

print("banana" in fruits)
print("durian" in fruits)
print(fruits.index("banana"))
print(fruits.count("banana"))
```

运行得：

```
True
False
1
2
```

### 拆解

- **`x in lst`**：x 在不在？返回 True / False
- **`lst.index(x)`**：x 在**第几个位置**（找不到报错 ValueError）
- **`lst.count(x)`**：x **出现了几次**

记忆：**in 答 yes/no，index 答几号，count 答几次**。

## 七、⚠️ 新手三大坑（5 分钟）

1. **`append` 没传值**：`pets.append()` 不报错但加了个 None。`pets.append("rabbit")` 必须传东西
2. **`remove` 找不到**：`pets.remove("unicorn")` → `ValueError: list.remove(x): x not in list`。**先用 in 检查**
3. **改 vs 重新赋值混淆**：`pets = ["new"]` 是**新建一个列表**，不是改原来的。`pets[:] = ["new"]` 才是改原列表

老规矩：踩坑 2 时故意 remove 不存在的值看报错。

**4.** 简单版本：
```python
nums = [3, 1, 4, 1, 5]
sorted_list = []
for n in nums:
    inserted = False
    for i, x in enumerate(sorted_list):
        if n < x:
            sorted_list.insert(i, n)
            inserted = True
            break
    if not inserted:
        sorted_list.append(n)
print("Sorted:", sorted_list)
```


**6.** 简化版：
```python
todos = []
while True:
    action = input("(add/done/list/quit): ")
    if action == "add":
        todos.append(input("New todo: "))
    elif action == "done":
        if todos:
            done = todos.pop(0)
            print(f"Done: {done}")
        else:
            print("Empty list")
    elif action == "list":
        for i, t in enumerate(todos):
            print(f"{i+1}. {t}")
    elif action == "quit":
        break
```
