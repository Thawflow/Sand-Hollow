# 沙坑课程文件批量编排

**触发**：给 `mentors-den/course/W*.md` 批量插入或修改内容块（课前胶囊/C++ 边栏/新一周课程稿）；猴哥下达"每周课程加 X / 全部课加 Y"类指示。

## 步骤

1. **内容表 + 生成器**：Python dict（文件名 → 元组：编号/主题/正文/判断题 或 引导/代码/认脸点），脚本存 `/tmp/gen-*.py`，跑完即弃。
2. **「」引号铁律**：中文正文里的引号一律写 `「」`——ASCII 直引号 `"` 会与 Python 字符串定界符冲突（曾因此两次返工，正则修复会误伤收尾定界符，只能整文件重写）。代码片段参数独立用三引号包裹。
3. **幂等锚点插入**（每文件先查标记串，已存在则 skip）：
   - 课首块：插在首个 `^## 一、` 之前
   - 课尾块：插在 `^## [一二三四五六七八九十]+、自查清单` 之前——**不带 `$` 尾锚**，标题常带后缀（如 "+ 🏅 本课成就"）
   - 自查勾选项：append 到 `- [ ] 🚀` 行之后；weekend 文件无自查清单结构，跳过勾选不算失败
4. **编号序列**按修业路径顺序排（含加餐挂点位，如加餐①=W13 文件挂 W08 后）；跨文件重编号用 sed 全量替换。
5. **验证**：抽 2-3 个文件 grep 新块标题 + `git diff --stat` 核对改动面；SYLLABUS 若有机制变化同步更新。
6. **交付**：新分支 `proposal/<topic>`，commit `[小马] course: <猴哥指示摘要>`，push 后 DM 冰爪 review——挂点调整权在她，Tree 终审节点写进 DM。

## 已知地形

- 胶囊格式已定型：`## ⓪ 🤖 课前 AI 一分钟 · 第 N 颗：<主题>` + 判断题 + `<details>` 答案 + 自查勾选；C++ 边栏：`## 👀 C++ 认脸时刻（1 分钟 · 只看不敲）` + cpp 代码块 + 认脸①②③
