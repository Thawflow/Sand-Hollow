Skyclan 家庭 12 周课程 · 一套材料，两位学员（ThawPaw 🐱 × Tree 🌳） 🎮 游戏大本营 ↗
⭐ 最佳学习姿势 · 分屏边看边练：左边开本站，右边开 Thonny，看一行写一行、写一行跑一行，不用靠记性来回切窗口。
Mac 🍎：拖窗口到屏幕最左/最右边缘 → 自动占半屏（或悬停绿色按钮 → 移到屏幕左侧/右侧）
Windows 🪟：按住 Win 再按 ← / → 一键半屏；Thonny 官网 thonny.org 有 Mac 和 Windows 版
开始前（只做一次）：喊你的 OpenClaw 分身，把 learning-homework 仓库克隆到用户 home 目录（推荐 ~/learning-homework），并让分身记住这个位置，以后的作业都写在这里。别放桌面——桌面有 macOS 隐私门卫（TCC）会拦 Thonny，还有 iCloud 同步捣乱。课程环境默认 Mac 🍎
克隆后告诉分身三件事：①仓库地址是 https://github.com/Thawflow/learning-homework（方便其他学员复制粘贴）；②读 mentors-den/mentors-rules.md 上岗手册（分身能自动 review 你的作业）；③帮你创建学员目录（<你的学员名>/homework/，如 thawpaw/homework/、tree/homework/、或你自创的英文名）并把这个路径记到它的 MEMORY/USER，以后作业统一放这里。
怎么用：每周左边选周 → 逐课阅读 → 学完勾选（进度自动保存在本机）→ 作业交到 <你的学员目录>/homework/ 目录（如 thawpaw/homework/、tree/homework/），批改回复会出现在 <你的学员目录>/reviews/（作业和评语分开放，更清楚）。 每周日晚如意发布下周内容。卡住随时喊 IcePaw / 如意 ❄️✨
